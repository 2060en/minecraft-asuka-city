# 告示牌大字（基岩版）

## 概要
用方塊字在告示牌上拼出「一個字母佔 3 格寬、4 行高」的大字，一塊板子大約放 3 個字母。字形照 Reddit r/Minecraft「Some new sign letters」：大寫是 Hugleton、小寫是 sreave15、數字和符號是 DaisyEseyad；網頁產生器在 https://main.daisyeseyad.workers.dev/bigsigntext 。

原作是 **Java 版**。它靠 Java 每個符號寬度不同（▊ ▏ ◢）拼出形狀，**不能直接貼進基岩版**。原因：基岩版只要一行混了方塊字就變成等寬字型，方塊字一個寬 9、半形空白一個寬 4，而且 ◢◣◤◥ 只是很小的三角形。所以這個技能保留原作的字母樣子，改用四分之一方塊重拼。

## 做法
1. **只有文字時，先問 作者 要靠左還是置中**（要求裡已經講了、或剛好塞滿每塊板子兩種一樣，就不用問；有符號時也不用問，見「符號」）。問之前先把兩種都跑一次（不加 `--png`），看各要幾塊板子、置中有沒有偏，再用 AskUserQuestion 問：
   - 選項寫成「置中（N 塊）」「靠左（N 塊）」。
   - 置中那行如果印出「偏右／偏左約 …」，再加一個「置中多一塊（N+1 塊，正中間）」，對應 `--center --boards N+1`。
2. 在 repo 根目錄跑產生器（只需要 Pillow 套件）。整串字一次給，程式會自己分板子：
   ```
   python .claude/skills/drawing-big-sign-letters/告示牌大字.py "FamilyMart" --center --png <工作暫存資料夾>/預覽.png
   ```
   參數：`--center` 整排置中（不加就是靠左）；`--boards N` 置中時指定幾塊；`--upper` 全部轉大寫；`--white` 預覽成白字（深色木頭用）；`--wood 緋紅` 預覽用哪種木頭的顏色（橡木、雲杉、白樺、叢林、金合歡、深色橡木、紅樹林、櫻花、竹、緋紅、詭異）；`--style 名稱` 換用 `STYLES` 裡的字形；`--sheet 字母表.png` 畫整套字母。
   - `--tail 3:案内所`：在最後面接一般打字的漢字、假名，放在指定的那一行（每字寬 9，跟方塊一樣算）。2026-11-12「INFORMATION」第 4 塊的 O N 右邊、第 3 行接「案内所」，剛好 89。漢字用日文漢字（内，不是內）。
   - 要還原品牌標誌時，先看標誌圖：大小寫照標誌，特殊的字母（例如 Costa 的 S、A）做成 `STYLES` 裡的品牌字形，預覽用接近標誌底色的木頭給 作者 挑。2026-11-12「Costa Coffee」：`--upper --style Costa`，緋紅木或紅樹林木配白字。
3. 回覆 作者，依序寫這四項：
   - 共幾塊板子、排法（靠左或置中）、由左到右貼在相鄰的方塊上；有單字換板子的地方要講。
   - 每塊一個程式碼區塊（4 行），內容**照程式輸出原樣貼**，標明「第 N 塊：哪幾個字母」。
   - 預覽圖傳給作者（先自己看過）。
   - 還沒在遊戲裡驗證過的地方（見下面）。
4. 作者 在遊戲裡看過、覺得哪個字母要改，就改 `告示牌大字.py` 裡的 `FONT` 字母表，再跑 `--sheet` 檢查。

## 速查
| 項目 | 規則 |
|---|---|
| 一行寬度 | 方塊字 9、半形空白 4，一行最多 89 |
| 一格空白 | 只能用半形空白湊（2 個＝8，比方塊少 1）。程式把連續空格加字距整段算，再 4 行一起窮舉行頭行尾空白，讓同一欄上下落差最小 |
| 會微微歪 | 同一欄方塊上下最多差 1～2 單位（約六分之一格），這是基岩版的極限，程式已經壓到理論最小。作者 問為什麼歪時照這個解釋 |
| 字距 | 同一塊板子上，字母之間空 1 個半形空白；兩塊板子交界本身就差不多是一個字距 |
| 一塊放幾個 | 字母、數字全部 3 格寬，一塊固定放 3 個（剛好 89）；標點比較窄 |
| M、W | 刻意做成 3 格（頂端或底部中間凹一格）。4 格版比較像，但一塊塞不下 3 個字，字距會亂，不要改回去 |
| 字母不切開 | 一個字母只會在同一塊板子上，換板子的地方一定落在字母之間 |
| 換單字的板子 | 後面接著換單字、又沒塞滿的板子，字一律靠左（接著前一塊），空出來的位置當單字間隔。2026-11-12「Costa Coffee」：第 2 塊只有 ta，置中的話會變成「Cos ta Coffee」 |
| 靠左 | 每塊盡量塞滿，空的位置都在最右邊那塊 |
| 置中 | 第 1 塊的字靠右、最後一塊靠左、中間照常，板子交界的字距照樣平均；程式挑「第 1 塊放幾個字」讓左右空白一樣。字數不巧時會偏半個字，多一塊板子就能正中間 |
| 行尾空白 | 有算進置中，**不能刪** |

## 符號
跑 `--list` 看有哪些。目前都是 作者 在遊戲裡確認過的現成寫法，存在程式的 `SYMBOLS`：

| 符號 | 是什麼 |
|---|---|
| ↑ | 往上（往前直走）：AKQ 出発口大箭頭 |
| ← → | 往左、往右：實心小頭＋細箭桿 |
| ↙ ↘ | 往左下、往右下（往樓下）：作者 改過的斜箭頭標準寫法 |
| 🏃 | 逃生出口的跑步小人：一般英文符號拼的細線（像素字型），照 NextGamer 影片 |
| ㊞ | 紅色印章：實心方塊刻白色菱形花紋，每行開頭 `§4`（深紅）。2026-11-12 給「春水堂」加的，例如 `"㊞春水堂"` |
| ⍰ | 圈圈問號（在 `FONT` 裡，寬 9 格，自己一塊）：4 行高的大問號，左右各一道弧線。上下封口的圈圈只放得下兩行高的小問號，不好認，存在 `--style 圈圈封口`。2026-11-12 做的 |

**顏色代碼**：基岩版告示牌可以用 `§` 加一個字換顏色（`§4` 深紅、`§c` 亮紅、`§6` 金、`§f` 白、`§0` 黑、`§r` 回到原本顏色…，表在程式的 `COLOR_CODES`）。代碼不顯示、不佔寬度，產生器算寬度、畫預覽都會跳過它；每行開頭都再打一次比較保險。2026-11-12 作者 把「㊞春水堂」蓋在春水堂店門上方：印章是紅的、`§4` 沒有顯示，確認可以用（同一行可以混不同顏色）。

- 每個符號**自己佔一塊板子**，照原樣輸出，空白是調過的，不能動。
- 字和符號可以一起給，例如 `"↑Departure"`、`"Gate 1→"`：文字照常分板子，並且**靠向符號那一邊**（符號在左就靠左、在右就靠右、兩邊都有就置中），所以不用問靠左還是置中。
- 指示系統的規矩：↑ 是往前直走；往樓下不用 ↓，用 ↙ ↘；箭頭放在它指的那一側。
- **新增符號**有兩種做法：
  - 照截圖或 作者 改好的文字原樣抄進 `SYMBOLS`。抄之前算好每行寬度：一整行都是一般英文符號時是像素字型，字寬查 `ASCII_W`；混了方塊字就是方塊 9、空白 4。
  - 新設計的用四分之一方塊畫進 `FONT`，程式會自動對齊。斜線用 ▞ ▚ 拼時，每行錯開 8 比錯開 9 連得順（作者 改過的 ↙ 就是這樣），這種要手調的放 `SYMBOLS`。
- 新加的符號一樣先跑 `--sheet` 看預覽再給 作者。

## 漢字、假名
目前有：中 華 そ ば（方塊風，2026-11-12「中華そば」）、春 水 堂（書法風，2026-11-12「春水堂」）。

- 告示牌只有 4 行，直的只有 8 個小方塊，所以漢字、假名做得比英文寬（5～7 格），**一塊板子一個字、每塊置中**，不用問靠左或置中。上下疊兩塊不行：上下兩塊告示牌之間會隔半格方塊的縫。
- 筆畫粗細跟英文字母一樣：直筆用整格 █、橫筆用半格 ▀▄。上下兩行之間本來就有縫，剛好把相鄰的橫筆分開。
- **新增一個字**：
  1. 先看遊戲字型裡這個字的 16×16 原形（遊戲字型圖只在作者本機，不在 repo）。
  2. 畫成 8 行的小方塊圖，筆畫要對齊「兩欄一格」，不要跨格，跨格會被格子縫切成兩條細線。
  3. 筆畫太多的字（例如華有 5 條橫線）要刪掉次要的筆畫。
  4. 用 `from_bitmap()` 換成 FONT 的寫法，跑 `--sheet` 看，最後給 作者 看。
- 華有兩版：兩側直筆變細（現在用的）、三根一樣粗（比較像「井」，寫在程式註解裡）。

### 書法風
- 除了四分之一方塊，還能用整個方塊字家族，做出粗細變化：
  - 下緣 1/8～7/8 高的 ▁▂▃▄▅▆▇
  - 左緣 1/8～7/8 寬的 ▏▎▍▌▋▊▉
  - 頂端 ▔、右緣 ▕
  - 網點 ░▒▓（試過，在遊戲裡會變成一塊灰，不好看）
- `字型轉方塊.py` 可以把電腦裡的字型畫到格子上，每格挑最像的方塊字：`python .claude/skills/drawing-big-sign-letters/字型轉方塊.py 春水堂 --font SIMLI.TTF --cells 9 --stretch 1.6 --bold 0.5 --png 預覽.png`。2026-11-12 試過：
  - 華文行楷、方正舒體、標楷體：筆畫太細，縮到 4 行就散掉。
  - 隸書（SIMLI.TTF）：扁寬、橫筆為主，最撐得住。
  - 自動結果還是糊（一格只能放一個形狀，同一格裡有兩條橫線就合在一起），只能當參考，最後要手工畫。
- **作者 的選擇（2026-11-12）**：比較過後，作者 圈了**標楷體自動轉換**那組（`--font kaiu.ttf --cells 8 --stretch 1.4 --bold 0.5`），說「感覺不錯」。它現在是「春水堂」的預設。
  - 手工的隸書兩版存在 `STYLES`，用 `--style 隸書一`、`--style 隸書二` 切換。第二版被說「怪怪的，還不如上一版」。
  - 所以書法字**先用字型轉方塊.py 跑幾種字型給 作者 挑**，不要自己判斷哪個好認就手工重畫。手工規則只在 作者 要修某個地方時參考。
- 手工畫的原則（2026-11-12 第二版，作者 在遊戲裡看過第一版後改的）：
  - **第一版的教訓**：9 格寬、用 ▁▂▃ 細橫條做「蠶頭燕尾」，蓋出來太扁、太空，細筆遠看會消失，作者 覺得「有一點形狀但不夠好」。
  - 字收窄到 7 格，比較方正；主筆畫至少半格粗，用整格 █ 當骨架（中間的直筆）。
  - 每行只放一條橫筆，讓行跟行之間的縫把筆畫分開。
  - 撇、捺用斜的四分之一方塊 ▞▚▟▙ 一路接下去，做出「人」「水」的動勢。
  - 書法感靠收筆的粗腳（捺的尾巴用 ▆）和撇的細尖（▂ ▝），不要整條都用細線。
  - 次要的筆畫刪掉（例如「春」下面的「日」只畫成一塊、「堂」的「土」少一橫）。
  - 字的兩端不要放孤立的小方塊（▗▖），遠看像多出來的點。

## 字母表格式
`FONT` 裡每個字母是「4 行用空白隔開，一個字元一格，`.` 是空格」，例如 `"A": "▟█▙ █.█ ███ █.█"`。4 行的格數必須一樣。只能用方塊字家族（U+2580～259F）：四分之一方塊 `█ ▀ ▄ ▌ ▐ ▘ ▝ ▖ ▗ ▚ ▞ ▛ ▜ ▙ ▟`，加上 `▁▂▃▅▆▇ ▏▎▍▋▊▉ ▔ ▕ ░▒▓`（形狀見 `block_mask()`，預覽圖照這個畫）。小寫的第 1 行留給往上伸的筆畫（b d f h i j k l t）。

## 半邊的字寬度不固定（2026-11-12 測試牌量過）
- 作者 蓋標楷體版春水堂歪掉，又蓋了測試牌（每行重複 4 個同樣的字，跟 ████ 比）：▌≈5、▝≈5、▏≈2、▕≈2、▐≈9、▂＝9。只畫一半或一小條的字會被**從字的左緣畫起、寬度變窄**（▐ 是例外），後面的字跟著往左擠。
- 但英文字母裡的「▌█▐」「▝█▘」在遊戲裡看起來又是整格 9（作者 看過 FamilyMart、Yoshinoya 說跟預覽一樣），規則還沒搞清楚。
- **新設計（書法字、漢字、新符號）一律只用左右兩邊都畫到的字**：`█▀▄▁▂▃▅▆▇▔▙▛▜▟▚▞`（`字型轉方塊.py` 的 `SAFE`，預設只用這些）。預覽圖對這些字是準的。
- 英文字母、數字裡已經用的 ▘▝▖▗▌▐ 先不改；如果 作者 之後發現哪個字母歪，就改成 SAFE 的寫法。

- 2026-11-11 作者 照產生器蓋了 Yoshinoya（3 塊），說跟預覽圖一樣；英文大字的預覽圖可以直接拿來給 作者 看樣子（半邊的字要小心，見上一節）。
- 字母表裡以後新加的字，一樣先跑 `--sheet` 看預覽，不用請 作者 實測。
- 2026-11-11 FamilyMart 截圖量過：方塊間距正好 9、行距 10（上下行之間有約 2 單位的縫），跟預覽一致。
- 2026-11-11 測試牌：沒有「看不見又寬 9」的字可以當空格。全形空白（U+3000）寬 9 但會畫出寫著 IDSP 的虛線框；點字空白（U+2800）只有 4 寬還有小點；字型圖裡空白的字（如 U+3040）看不到但也只有 4 寬。不要再找了。

## 常見錯誤
- 沒先問靠左還是置中就直接給（作者 2026-11-11 要求：要先問，招牌常常要置中）。
- 大寫字母的最上面一行、最下面一行用半格（▄ ▀）當頂端或底部：字母會比旁邊的矮一截。頂端、底部要用整格 █ 或 ▟▙▜▛（佔滿上半或下半的那一側），讓每個字母一樣高（作者 2026-11-12：Costa 的 A 頂端用 ▄，「A 會比其他字母低，很怪，用全磚」）。
- 自己手打或手改空白：空白數是程式算過對齊的，改一個就歪。
- 把 Java 原作的字串（含 ▊ ▏ ◢ ◣）直接給 作者。
- 回覆時把只有空白的那一行刪掉，或把行尾空白吃掉，這樣 4 行會錯位。
- 字母表裡沒有的字（例如 &、/）：程式會列出來，要先在 `FONT` 加上，再跑 `--sheet` 給 作者 看。
