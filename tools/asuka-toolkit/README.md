# Asuka 工具包

建造 Asuka City 用的工具：放進世界的行為包，每樣工具拿在手上操作，一樣東西只做一件事，介面幾乎只有一層（作者定的，2026-11-05）。

| 拿在手上 | 操作 | 效果 |
| --- | --- | --- |
| 木棍 | 右鍵 | 開快速建造設定；復原在第二層 |
| 木棍 | 蹲下右鍵 | 開關快速建造 |
| 烈焰棒 | 揮一下或右鍵 | 開收藏清單，按一下就拿一份 |
| 烈焰棒 | 蹲下右鍵點方塊 | 收藏那個方塊；點物品框架就收藏框架裡的物品 |
| 烈焰棒 | 蹲下對空氣右鍵 | 收藏快捷列裡烈焰棒右邊那一格的物品 |
| 旋風棒 | 揮一下或右鍵 | 開特殊物品，按一下就放進包包 |

拿著這三樣東西點方塊時，方塊本身的功能（開門、開箱子）不會觸發。拿烈焰棒、旋風棒左鍵點方塊時，只會開介面，不會把方塊打掉。

**永遠是獨立的包，不併進 Asuka tech**（作者決定，2026-11-04，除非作者之後改主意）：工具包出錯時不會連累主世界依賴的自製方塊；更新工具包不用動 Asuka tech 的版本；也可以單獨用在其他世界，或單獨關掉。

> **狀態：作者在 `CX198-test` 測過，都正常（2026-11-05）。** 還沒用到主世界。

作者決定不要的功能：常用物品選單、時間與天氣（指令夠短，2026-11-05）；在遊戲聊天框和 Claude 對話的「AI 聊天」擱置（2026-11），程式碼留在分支 `ccr-b47c32a1-gp7z7e` 的 `tools/asuka-toolkit/ai-chat/`。

## 符合可拔除原則

只有腳本，沒有新增任何自訂方塊、物品或實體：

- 放下的方塊、拿到的物品都是原版的，拔掉行為包之後全部留著
- 只用穩定版 Script API（`@minecraft/server` 2.6.0、`@minecraft/server-ui` 2.1.0），**不需要開啟任何實驗性功能**
- 寫進存檔的資料：
  - 玩家的快速建造設定（幾十個字元），拔掉後不會被讀取
  - 物品收藏的清單（名稱與結構名稱），拔掉後不會被讀取
  - 物品收藏的內容存成原版的結構（`asuka:fav_xxxx`），和結構方塊存的結構一樣；拔掉行為包後還是可以用 `/structure load asuka:fav_xxxx ~ ~ ~` 叫出裝著物品的箱子

因此符合 [`docs/technical.md`](../../docs/technical.md) 的「拔掉之後不影響體驗，放了錦上添花」。

## 安裝

**測試時用開發版**，不用匯入，改完重新跑一次、重新進世界就看得到（作者實測，2026-11-05）：

```bash
python tools/asuka-toolkit/build.py --dev
```

它會放進遊戲的開發用資料夾。到測試世界的世界設定 → 行為包，啟用「Asuka 工具包 DEV」。

**正式版**：

```bash
python tools/asuka-toolkit/build.py
```

組出 `addon/build/Asuka toolkit v<版本號>.mcpack`，雙擊匯入，到世界設定啟用「Asuka 工具包」。版本號自動加；匯入新版時舊版不會被蓋掉，要自己到遊戲的設定裡刪（Asuka tech 的實測，2026-11-04）。

- 同一個世界不要同時啟用開發版和正式版
- 確認「實驗性功能」裡的選項全部保持關閉。如果遊戲要求開啟「Beta API」，代表版本對不上，**不要開**，先回報問題
- 需要 Minecraft 基岩版 1.26.0 以上

## 快速建造（木棍）

開啟後，放下一顆方塊，就朝面向的方向自動補上後面幾格；**打掉一顆方塊，就朝面向的方向打掉後面幾格**，不用另外切換模式。每次進入世界時都是**關閉**的，避免一進去就不小心長出一整排。設定會記住。

補上的方塊和第一顆完全一樣，包括朝向：樓梯、原木、半磚（上半／下半）、鐵軌的方向都會照抄。門、高草、向日葵這種兩格高的方塊，上半部會一起複製，Asuka tech 的白色門、淺灰色門也一樣。

打掉的方塊不會掉物品（作者要求，2026-11-05）。

### 設定

| 項目 | 說明 | 預設 |
| --- | --- | --- |
| 範圍 | 幾格內，含親手放或打的第一顆（1～1000） | 20 |
| 間隔 | 中間空幾格（0～256）。範圍 20、間隔 2 是第 1、4、7…19 格，共 7 顆；0 是連續一整排 | 0 |
| 方向 | 見下方「方向模式」 | 水平 |
| 可以蓋掉 | 只放空氣／空氣和液體（水、岩漿）／全部覆蓋 | 全部覆蓋 |
| 破壞時只打 | 全部／和第一顆同一種的方塊 | 全部 |

基岩和箱子等容器一律不蓋掉、不打掉，因為容器裡的東西沒辦法復原。線上碰到不能動的格子會跳過，繼續往後；超出世界高度或碰到還沒載入的區塊才提早停下。

### 方向模式

| 模式 | 方向 | 適合 |
| --- | --- | --- |
| 水平（預設） | 東西南北加四個斜角，共八個方位。抬頭或低頭超過 75° 時改成垂直 | 道路、牆、路燈、行道樹、柱子 |
| 立體 | 水平八方位 × 往上斜、水平、往下斜，再加正上、正下，共 26 個方位 | 樓梯、斜坡、斜向的支架 |
| 自由 | 完全照視線方向，任意斜率都可以（例如 1:3 的緩坡） | 特殊角度；比較難瞄準 |

水平和立體模式會把方向「吸附」到最近的方位，所以視線稍微歪一點，蓋出來的線還是筆直的。

放方塊時，如果線的第一步正好要鑽進第一顆貼著的方塊，就會自動反過來長：看著地面放往上長柱子；看著天花板放往下垂；看著牆面放從牆面往外長。打方塊則一律順著視線往裡打。

### 復原

可以復原最近 20 次。木棍右鍵的設定頁勾選「復原」再按套用，會打開復原頁面（設定頁只能有一顆送出鈕，所以復原放第二層，作者定的，2026-11-05）。在復原頁面按了復原，頁面不會消失，可以連按好幾次（遊戲的表單按任何按鈕都會關，所以是馬上重開同一頁，會閃一下），按 X 離開。

- 放置：只收回自動補上的方塊，不包含自己放的第一顆（用手打掉就好）
- 破壞：連第一顆也還原，但第一顆是門這種兩格高的方塊時除外
- 被蓋掉的方塊（例如水）會還原
- 復原紀錄只存在記憶體，離開世界後就會清空

鍵盤快捷鍵（Ctrl+Z）做不到：腳本只偵測得到跳躍和蹲下這兩個按鍵。

## 物品收藏（烈焰棒）

把染好色、印好圖案的旗幟、盾牌存起來，之後在哪裡都能拿出一份。按完清單不會關，可以連續拿好幾樣；包包滿了，清單會關掉，在畫面下方顯示一行提示。

手上拿著烈焰棒，就不能同時拿要收藏的東西，所以有這幾種收藏法：

| 對著什麼 | 結果 |
| --- | --- |
| 放著的旗幟或其他方塊 | 收藏打掉後掉落的東西。玻璃這種打掉不掉東西的會直接告訴你不行；箱子的內容物會一起收進來 |
| 物品框架 | 收藏框架裡的物品（盾牌、地圖、書），框架本身不算 |
| 空氣 | 收藏快捷列裡烈焰棒右邊那一格的物品，物品留在原位。烈焰棒在最右邊時沒有右邊那一格 |

同一種物品收藏好幾個時，名稱後面會加編號（例如「白色旗幟 #2」）。清單最下面的「刪除收藏」可以刪掉不要的；沒有改名功能（作者決定，2026-11-05）。

**做法：** 和結構方塊一樣。收藏時在頭頂高空暫時放一個箱子，把物品放進去存成結構，再把箱子移掉；拿取時把結構放回高空，從箱子裡拿出物品，再移掉箱子。收藏方塊時，是先在高空放一份複製品再打掉，把掉落物放進箱子，所以世界裡原本的方塊不會動到。作者的世界關掉了方塊與實體掉落（`doTileDrops`、`doEntityDrops`），所以收藏時會暫時打開這兩個規則，拿到掉落物就還原成原本的設定（約 0.1 秒，這段時間世界裡其他方塊被打掉也會掉物品）。

## 特殊物品（旋風棒）

創造模式物品欄裡沒有、平常要用 `/give` 才拿得到的東西，作者選的（2026-11-05）：結構方塊、結構空位、屏障、光源方塊（亮度 15）、指令方塊、重複指令方塊、連鎖指令方塊。要改清單就改 `behavior_pack/scripts/catalog.js`，然後重新組包。

按一下就放進包包，清單跟著關掉（作者要求，2026-11-05）；包包滿了在畫面下方顯示一行提示。

## 限制

- 快速建造不會複製箱子裡的物品、告示牌的文字、旗幟的圖案等「方塊實體」資料，只會複製方塊本身；被蓋掉或打掉的告示牌、旗幟，復原後也只有方塊本身
- 快速建造不支援床（床是兩格，而且顏色存在方塊實體裡），快速破壞也會跳過床
- 火把、按鈕、鐵軌等需要依附的方塊，快速建造補上的可能是懸空的，遇到方塊更新時可能會掉落；快速破壞打掉支撐的方塊時，依附在上面的東西也可能掉物品
- 返回鍵沒辦法放在左上角：遊戲內建的表單只能由上往下排按鈕，要改位置得用資源包改遊戲介面，工具包就不再是只有腳本。現在只有復原和刪除收藏有第二層：復原頁面按 X 離開，刪除收藏按 X 回收藏清單
- 物品收藏需要頭頂上方有空位（通常是世界頂端的空氣），在很高的地方或蓋滿方塊的高空可能找不到空位
- 物品收藏裡放了 Asuka tech 的自製物品時，轉換程式 `convert.py` 會因為不知道怎麼處理而停下來，規則待決定（見 [docs/addon.md](../../docs/addon.md#53-asuka-工具包)）

## 開發

```
tools/asuka-toolkit/
├── behavior_pack/              行為包本體
│   ├── manifest.json
│   └── scripts/
│       ├── main.js             入口：事件，判斷手上拿什麼
│       ├── ui.js               共用：提示訊息、顯示表單
│       ├── input.js            左鍵判斷（純計算）
│       ├── quickbuild.js       快速建造與快速破壞
│       ├── line.js             方向與座標計算（純計算）
│       ├── favorites.js        物品收藏
│       ├── special.js          特殊物品
│       └── catalog.js          特殊物品清單（純資料）
├── test/                       純計算部分的單元測試
├── build.py                    組包：正式版與開發版
└── release.json                正式版的版本號與內容雜湊
```

單元測試要 [Node.js](https://nodejs.org/) 22 以上，不需要安裝套件；組包要 Python 3，只用內建功能。

```bash
npm test --prefix tools/asuka-toolkit
```

想換工具：修改 `behavior_pack/scripts/main.js` 開頭的 `QUICK_BUILD_TOOL`、`FAVORITES_TOOL`、`SPECIAL_TOOL`，然後重新組包。
