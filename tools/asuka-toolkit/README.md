# Asuka 工具包

建造 Asuka City 用的整合工具，分成兩個部分：

| 部分 | 是什麼 | 功能 |
| --- | --- | --- |
| [行為包](#行為包) | 放進世界的行為包，拿木棍右鍵開選單 | 快速建造、常用物品、物品收藏（旗幟、盾牌）、時間與天氣 |
| [AI 聊天](#ai-聊天) | 在電腦上執行的小程式，遊戲用 `/connect` 連過去 | 在聊天框打字，由 Claude 回答；Claude 讀過這個 repo 的設定文件 |

AI 聊天沒辦法做進行為包：行為包在一般的世界裡不能對外連網（能連網的 `@minecraft/server-net` 只能在專用伺服器使用），所以改用遊戲內建的 `/connect` 連到電腦上的程式。

> **狀態：開發中，還沒在遊戲裡實測。** 計算的部分有單元測試；行為包用模擬的遊戲環境跑過完整流程，AI 聊天用假的 Claude API 和假的 Minecraft 跑過完整流程。但還沒在真正的 Minecraft 裡試過，請先在世界的副本上測試，見下方「待驗證」。

## 符合可拔除原則

**行為包**只有腳本，沒有新增任何自訂方塊、物品或實體：

- 放下的方塊、拿到的物品都是原版的，拔掉行為包之後全部留著
- 只用穩定版 Script API（`@minecraft/server` 2.1.0、`@minecraft/server-ui` 2.1.0），**不需要開啟任何實驗性功能**
- 寫進存檔的資料：
  - 玩家的設定（快速建造的數量、間隔等，幾十個字元），拔掉後不會被讀取
  - 物品收藏的清單（名稱與結構名稱），拔掉後不會被讀取
  - 物品收藏的內容存成原版的結構（`asuka:fav_xxxx`），和結構方塊存的結構一樣；拔掉行為包後還是可以用 `/structure load asuka:fav_xxxx ~ ~ ~` 叫出裝著物品的箱子

**AI 聊天**是外部程式，只會送 `tellraw`、`titleraw`（顯示文字）和 `querytarget`（讀玩家座標）這幾個指令，不會修改世界。

因此兩者都符合 [`docs/technical.md`](../../docs/technical.md) 的「拔掉之後不影響體驗，放了錦上添花」。

## 行為包

### 安裝

1. 下載 [`dist/asuka-toolkit.mcpack`](dist/asuka-toolkit.mcpack)，雙擊檔案，Minecraft 會自動匯入
2. 先**複製一份世界**來測試（世界清單 → 編輯 → 複製世界）
3. 在副本的世界設定 → 行為包 → 找到「Asuka 工具包」→ 啟用
4. 確認「實驗性功能」裡的選項全部保持關閉。如果遊戲要求開啟「Beta API」，代表版本對不上，**不要開**，先回報問題
5. 進入世界，拿一根木棍右鍵，看到「Asuka 工具包」選單就成功了

需要 Minecraft 基岩版 1.21.100 以上（2025 年 8 月以後的版本）。

移除：世界設定 → 行為包 → 選擇「Asuka 工具包」→ 移除。

### 操作

| 操作 | 效果 |
| --- | --- |
| 拿木棍右鍵 | 開主選單：快速建造、常用物品、物品收藏、時間與天氣 |
| 拿木棍**蹲下**右鍵 | 直接開關快速建造（不開選單） |
| `/asuka:menu` | 開主選單（備用，木棍不方便時用） |
| `/asuka:undo` | 復原上一次快速建造（備用） |

拿著木棍點方塊時，方塊本身的功能（開門、開箱子）不會觸發，只會開選單。

### 快速建造

仿照以前「多玩我的世界盒子」的快速建造：開啟後放下一顆方塊，就會朝你面向的方向自動補上後面幾格，不用輸入指令。

每次進入世界時，快速建造都是**關閉**的，避免一進去就不小心長出一整排。設定（數量、間隔等）會記住。

後面補上的方塊和第一顆完全一樣，包括朝向：樓梯、原木、半磚（上半／下半）、鐵軌的方向都會照抄。門、高草、向日葵這種兩格高的方塊，上半部會一起複製。

#### 設定項目

| 項目 | 說明 | 預設 |
| --- | --- | --- |
| 數量 | 自動補上幾顆，不含自己放的第一顆（1～1000） | 20 |
| 間隔 | 每顆之間空幾格（0～256）。0 是連續一整排；3 是「放一顆、空三格、再放一顆」 | 0 |
| 方向 | 見下方「方向模式」 | 水平 |
| 可以覆蓋哪些方塊 | 只放空氣／空氣和液體（水、岩漿）／全部覆蓋 | 空氣和液體 |
| 遇到放不下的位置 | 停下來／跳過，繼續往後放 | 停下來 |

「全部覆蓋」也不會蓋掉基岩和箱子等容器，因為容器裡的東西沒辦法復原。

#### 方向模式

| 模式 | 方向 | 適合 |
| --- | --- | --- |
| 水平（預設） | 東西南北加四個斜角，共八個方位。抬頭或低頭超過 75° 時改成垂直 | 道路、牆、路燈、行道樹、柱子 |
| 立體 | 水平八方位 × 往上斜、水平、往下斜，再加正上、正下，共 26 個方位 | 樓梯、斜坡、斜向的支架 |
| 自由 | 完全照視線方向，任意斜率都可以（例如 1:3 的緩坡） | 特殊角度；比較難瞄準 |

水平和立體模式會把方向「吸附」到最近的方位，所以視線稍微歪一點，蓋出來的線還是筆直的。

#### 自動反向：長柱子、從牆面往外長

如果線的第一步正好要鑽進「第一顆方塊貼著的那顆方塊」，就會自動反過來長：

- 看著**正下方的地面**放 → 往上長柱子（電線桿、路燈桿、橋墩）
- 看著**天花板**放 → 往下垂（吊燈的鍊子）
- 看著**牆面**放 → 從牆面往外長（雨遮、招牌支架）

#### 復原

快速建造選單裡的「復原上一次」可以收回最近 20 次快速建造：

- 只收回自動補上的方塊，**不包含自己放的第一顆**（第一顆用手打掉就好）
- 被覆蓋掉的方塊（例如水）會還原
- 復原紀錄只存在記憶體，離開世界後就會清空

### 常用物品

創造模式物品欄裡沒有、平常要用 `/give` 才拿得到的東西，按一下就放進背包。

| 分類 | 內容 |
| --- | --- |
| 建造輔助 | 結構方塊、結構空位、屏障、邊界、允許、拒絕、拼圖方塊 |
| 指令方塊 | 指令方塊、重複指令方塊、連鎖指令方塊、指令方塊礦車 |
| 特殊方塊 | 生怪磚、試煉生怪磚、寶庫、石化橡木半磚、霜冰 |
| 生怪蛋 | 鐵魔像、雪人、凋零怪、終界龍 |
| 光源方塊 | 用滑桿選亮度 0～15，會記住上次選的亮度 |
| 自訂清單 | 自己加的常用物品 |
| 輸入物品 ID | 輸入任何物品 ID 和數量就能拿；填上名稱就會加進自訂清單 |

要長期改清單內容，修改 `behavior_pack/scripts/catalog.js`，然後重新打包。

### 物品收藏

把染好色、印好圖案的旗幟、盾牌存起來，之後在哪裡都能拿出一份，不用重新染色印圖案。不只旗幟和盾牌，任何物品都可以收藏：地圖畫、寫好的書、改過名字的物品、附魔物品等。

1. 把要收藏的物品拿在手上
2. 主選單 → 物品收藏 → 收藏手上的物品，取個名字（例如「津蘭國旗」）
3. 之後在物品收藏的清單按一下，就會拿出一份；收藏本身不會減少

收藏時拿著幾個就存幾個：拿著 16 面旗幟收藏，之後每次就拿出 16 面。「管理」可以改名或刪除。

**做法：** 和結構方塊一樣。收藏時在你頭頂的高空暫時放一個箱子，把物品放進去存成結構，再把物品拿回你手上、把箱子移掉；拿取時把結構放回高空，從箱子裡拿出物品，再移掉箱子。所以旗幟的圖案、附魔、名稱等資料都會原封不動保留，而且收藏存在世界裡，換電腦或拔掉行為包都不會不見。

### 時間與天氣

| 按鈕 | 效果 |
| --- | --- |
| 切到半夜／切回白天 | 依照現在的時間顯示其中一個，一鍵切換。半夜（18000）最暗，適合看燈光效果 |
| 日出、白天、正午、日落、晚上、半夜 | 直接跳到這個時間 |
| 自訂時間 | 用滑桿選時間 |
| 時間流動 | 開關日夜循環（`doDayLightCycle`）。關掉就會固定在現在的時間 |
| 晴天、下雨、雷雨 | 切換天氣 |
| 天氣變化 | 開關天氣循環（`doWeatherCycle`） |

### 限制

- 快速建造不會複製箱子裡的物品、告示牌的文字、旗幟的圖案等「方塊實體」資料，只會複製方塊本身（要複製帶圖案的旗幟，用物品收藏）
- 快速建造不支援床（床是兩格，而且顏色存在方塊實體裡）
- 火把、按鈕、鐵軌等需要依附的方塊，快速建造補上的可能是懸空的，遇到方塊更新時可能會掉落
- 前方的區塊還沒載入（超出視野距離）時，快速建造會提早停下
- 物品收藏需要你頭頂上方有空位（通常是世界頂端的空氣），在很高的地方或蓋滿方塊的高空可能找不到空位

## AI 聊天

在 Minecraft 聊天框打字，由 Claude 回答。Claude 讀過這個 repo 的 `CLAUDE.md` 和 `docs/` 底下所有設定文件，可以問它設定、請它檢查合理性、幫忙想名字（會遵守命名黑名單），也能上網查現實資料（例如「台北 101 多高」）。

### 準備

1. 安裝 [Node.js](https://nodejs.org/)（22 以上）
2. 在 [Claude Console](https://platform.claude.com) 建立 API 金鑰
3. 把這個 repo clone 到電腦上（程式會讀 repo 裡的設定文件）
4. 在 `tools/asuka-toolkit/ai-chat/` 裡，把 `config.example.json` 複製成 `config.json`，把 API 金鑰填進 `apiKey`
   - `config.json` 已經列在 `.gitignore`，不會被 commit
   - 也可以不填，改用環境變數 `ANTHROPIC_API_KEY`
5. Minecraft 的設定 → 一般 → 關閉「需要加密的 WebSocket」（Require Encrypted Websockets）。如果找不到這個選項，可以先不管，連不上時再回來看

### 使用

1. 雙擊 `tools/asuka-toolkit/ai-chat/start.bat`（第一次會自動安裝套件），看到「準備好了」
2. 進入世界，在聊天框輸入 `/connect localhost:3000`（需要開啟作弊）
3. 聊天框出現「[Claude] 已連線！」之後，直接打字就能聊天

| 聊天框輸入 | 效果 |
| --- | --- |
| 一般文字 | 傳給 Claude，回答會顯示在聊天框 |
| `!reset` | 開始新的對話（清掉前面的對話內容） |
| `!usage` | 看這次啟動以來的 token 用量和估計花費 |
| `!help` | 看說明 |

- 指令（`/` 開頭）不會傳給 Claude
- 每則訊息會自動附上你的座標和維度，問「我現在在哪附近」之類的問題時用得到
- 對話紀錄存在 `ai-chat/logs/日期.md`（不會被 commit）。聊天中確定的新設定不會自動寫進文件，可以之後把紀錄交給 Claude Code 整理
- 改了設定文件之後，重新啟動程式才會讀到新的內容

### 設定（config.json）

| 欄位 | 說明 | 預設 |
| --- | --- | --- |
| `apiKey` | API 金鑰；留空時用環境變數 `ANTHROPIC_API_KEY` | 空 |
| `port` | WebSocket 埠號，`/connect` 時用 | 3000 |
| `model` | 使用的模型 | `claude-opus-5-5` |
| `effort` | 思考深度：`low`、`medium`、`high`、`xhigh`、`max`。聊天用 `low` 回得最快 | `low` |
| `prefix` | 只回應這個開頭的訊息，例如 `@`；空字串代表回應所有聊天訊息 | 空 |
| `webSearch` | 是否讓 Claude 上網查資料 | `true` |
| `maxHistoryTurns` | 記住最近幾輪對話 | 10 |
| `repoRoot` | repo 根目錄，相對於 `ai-chat` 資料夾 | `../../..` |

### 費用

設定文件約 4.5 萬字，每次提問都會一起送出。程式用了 1 小時的提示快取（prompt caching），所以：

- 每小時第一次提問：要把文件寫進快取，約 US$0.3～0.4
- 之後一小時內的提問：文件從快取讀取，每則約 US$0.01～0.03
- 網路搜尋每次 US$0.01

以上是用 `claude-opus-5-5` 的價格估計的（輸入 US$4、輸出 US$20、快取讀取 US$0.2，都是每百萬 token），實際花費以 Claude Console 的帳單為準。`!usage` 會顯示這次啟動以來的估計。

### 安全

- 程式只接受本機（`127.0.0.1`）的連線，同一個網路的其他裝置連不進來，不會被別人用掉額度
- API 金鑰只存在你電腦上的 `config.json`

### 連不上時

- **輸入 `/connect` 後沒反應或馬上斷線**：確認程式有在執行、顯示「準備好了」；關閉 Minecraft 設定裡的「需要加密的 WebSocket」
- **舊的 UWP 版 Minecraft**：Windows 預設不讓 UWP 程式連到本機，要用系統管理員身分執行一次 `CheckNetIsolation LoopbackExempt -a -n="Microsoft.MinecraftUWP_8wekyb3d8bbwe"`。現在的 GDK 版應該不需要
- **埠號被占用**：把 `config.json` 的 `port` 改成別的數字，例如 3001，`/connect` 也跟著改

## 待驗證

還沒在遊戲裡實測，以下項目要在世界副本上確認：

**行為包**

- [ ] 行為包可以匯入、啟用，而且不會要求開啟實驗性功能
- [ ] 拿木棍對著空氣右鍵、對著方塊右鍵，都能開選單
- [ ] 蹲下拿木棍右鍵可以開關快速建造
- [ ] 快速建造：水平、立體、自由三種方向模式的手感，水平模式的 75° 門檻是否合適
- [ ] 快速建造：看著地面放方塊時，會往上長柱子（需要遊戲在放方塊前觸發「右鍵點方塊」事件）
- [ ] 快速建造：在水裡放半磚、柵欄等方塊時，後面補上的會不會保持含水
- [ ] 快速建造：復原是否正確；一次補 1000 顆時會不會卡頓
- [ ] 常用物品：每個物品都拿得到（特別是生怪蛋、試煉生怪磚、寶庫）
- [ ] 物品收藏：旗幟、盾牌的圖案有保留下來；收藏與拿取時沒有東西掉出來
- [ ] 時間與天氣：各按鈕正常

**AI 聊天**

- [ ] `/connect localhost:3000` 連得上（需不需要關閉「需要加密的 WebSocket」）
- [ ] 中文聊天訊息可以正確傳給程式，回答可以正確顯示
- [ ] 長回答分段顯示是否正常
- [ ] `querytarget @s` 能讀到座標
- [ ] 實際的 token 用量和費用

## 待決定

- AI 聊天要不要能執行遊戲指令（例如「幫我切到晚上」「把我傳送到機場」）。做得到，但要先決定哪些指令可以讓它執行、要不要每次確認
- 物品收藏要不要能一次拿出一整組（目前是收藏時拿幾個，之後就拿出幾個）

## 開發

```
tools/asuka-toolkit/
├── behavior_pack/              行為包本體
│   ├── manifest.json
│   └── scripts/
│       ├── main.js             入口：事件、主選單、備用指令
│       ├── ui.js               共用：提示訊息、顯示表單
│       ├── quickbuild.js       快速建造
│       ├── line.js             快速建造的方向與座標計算（純計算）
│       ├── items.js            常用物品
│       ├── catalog.js          常用物品清單（純資料）
│       ├── favorites.js        物品收藏
│       ├── environment.js      時間與天氣
│       └── clock.js            遊戲時間的換算（純計算）
├── test/                       行為包純計算部分的單元測試
├── build.js                    打包成 dist/asuka-toolkit.mcpack
├── dist/asuka-toolkit.mcpack   打包好的檔案，雙擊即可匯入
└── ai-chat/                    AI 聊天程式
    ├── server.js               入口：WebSocket 伺服器、處理聊天
    ├── lib/bedrock.js          /connect 的 WebSocket 協定、文字處理
    ├── lib/prompt.js           讀設定文件、組系統提示
    ├── lib/chat.js             呼叫 Claude API、對話紀錄、用量
    ├── test/                   單元測試
    ├── config.example.json     設定範例
    └── start.bat               Windows 雙擊執行
```

需要 [Node.js](https://nodejs.org/) 22 以上。

```
cd tools/asuka-toolkit
npm test        # 行為包的單元測試（不需要安裝套件）
npm run build   # 重新打包 dist/asuka-toolkit.mcpack

cd ai-chat
npm install     # 安裝 Claude SDK 和 ws
npm test        # AI 聊天的單元測試
```

修改行為包的程式後記得重新打包，並把新的 `.mcpack` 一起 commit。

開發時可以把 `behavior_pack` 資料夾直接複製到遊戲的 `development_behavior_packs` 資料夾（GDK 版的位置待確認，可能在 `%APPDATA%\Minecraft Bedrock\Users\Shared\games\com.mojang\development_behavior_packs`），改完程式在遊戲裡輸入 `/reload` 就能套用，不用重新匯入。

想換開選單的物品：修改 `behavior_pack/scripts/main.js` 開頭的 `MENU_ITEM`，例如改成 `'minecraft:blaze_rod'`（烈焰棒），然後重新打包。
