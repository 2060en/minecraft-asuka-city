# Asuka 工具包

建造 Asuka City 用的工具：放進世界的行為包，拿木棍右鍵開選單，有快速建造、常用物品、物品收藏（旗幟、盾牌）、時間與天氣。

**永遠是獨立的包，不併進 Asuka tech**（作者決定，2026-11-04，除非作者之後改主意）：工具包出錯時不會連累主世界依賴的自製方塊；更新工具包不用動 Asuka tech 的版本；也可以單獨用在其他世界，或單獨關掉。

> **狀態：開發中，還沒在遊戲裡實測。** 計算的部分有單元測試；行為包用模擬的遊戲環境跑過完整流程，但還沒在真正的 Minecraft 裡試過，請先在測試世界 `CX198-test` 上測試，見下方「待驗證」。

在遊戲聊天框和 Claude 對話的「AI 聊天」作者決定擱置（2026-11），沒有帶過來，程式碼留在分支 `ccr-b47c32a1-gp7z7e` 的 `tools/asuka-toolkit/ai-chat/`。

## 符合可拔除原則

只有腳本，沒有新增任何自訂方塊、物品或實體：

- 放下的方塊、拿到的物品都是原版的，拔掉行為包之後全部留著
- 只用穩定版 Script API（`@minecraft/server` 2.1.0、`@minecraft/server-ui` 2.1.0），**不需要開啟任何實驗性功能**
- 寫進存檔的資料：
  - 玩家的設定（快速建造的數量、間隔等，幾十個字元），拔掉後不會被讀取
  - 物品收藏的清單（名稱與結構名稱），拔掉後不會被讀取
  - 物品收藏的內容存成原版的結構（`asuka:fav_xxxx`），和結構方塊存的結構一樣；拔掉行為包後還是可以用 `/structure load asuka:fav_xxxx ~ ~ ~` 叫出裝著物品的箱子

因此符合 [`docs/technical.md`](../../docs/technical.md) 的「拔掉之後不影響體驗，放了錦上添花」。

## 行為包

### 安裝

**測試時用開發版**，不用匯入，改完重新跑一次、重新進世界就看得到（待實測）：

```bash
python tools/asuka-toolkit/build.py --dev
```

它會放進遊戲的開發用資料夾。到測試世界的世界設定 → 行為包，啟用「Asuka 工具包 DEV」。

**正式版**：

```bash
python tools/asuka-toolkit/build.py
```

組出 `addon/build/Asuka toolkit v<版本號>.mcpack`，雙擊匯入，到世界設定啟用「Asuka 工具包」。版本號自動加；匯入新版時舊版不會被蓋掉，要自己到遊戲的設定裡刪（Asuka tech 的實測，2026-11-04）。

- 同一個世界不要同時啟用開發版和正式版
- 確認「實驗性功能」裡的選項全部保持關閉。如果遊戲要求開啟「Beta API」，代表版本對不上，**不要開**，先回報問題
- 需要 Minecraft 基岩版 1.21.100 以上（2025 年 8 月以後的版本）

### 操作

| 操作 | 效果 |
| --- | --- |
| 拿木棍右鍵 | 開主選單：快速建造、常用物品、物品收藏、時間與天氣 |
| 拿木棍**蹲下**右鍵 | 直接開關快速建造（不開選單） |
| `/asuka:menu` | 開主選單（備用，木棍不方便時用） |
| `/asuka:undo` | 復原上一次快速建造（備用） |

拿著木棍點方塊時，方塊本身的功能（開門、開箱子）不會觸發，只會開選單。

### 快速建造

仿照以前「多玩我的世界盒子」的快速建造：開啟後放下一顆方塊，就會朝你面向的方向自動補上後面幾格，不用輸入指令。

每次進入世界時，快速建造都是**關閉**的，避免一進去就不小心長出一整排。設定（數量、間隔等）會記住。

後面補上的方塊和第一顆完全一樣，包括朝向：樓梯、原木、半磚（上半／下半）、鐵軌的方向都會照抄。門、高草、向日葵這種兩格高的方塊，上半部會一起複製，Asuka tech 的白色門、淺灰色門也一樣（待實測）。

#### 設定項目

| 項目 | 說明 | 預設 |
| --- | --- | --- |
| 數量 | 自動補上幾顆，不含自己放的第一顆（1～1000） | 20 |
| 間隔 | 每顆之間空幾格（0～256）。0 是連續一整排；3 是「放一顆、空三格、再放一顆」 | 0 |
| 方向 | 見下方「方向模式」 | 水平 |
| 可以覆蓋哪些方塊 | 只放空氣／空氣和液體（水、岩漿）／全部覆蓋 | 空氣和液體 |
| 遇到放不下的位置 | 停下來／跳過，繼續往後放 | 停下來 |

「全部覆蓋」也不會蓋掉基岩和箱子等容器，因為容器裡的東西沒辦法復原。

#### 方向模式

| 模式 | 方向 | 適合 |
| --- | --- | --- |
| 水平（預設） | 東西南北加四個斜角，共八個方位。抬頭或低頭超過 75° 時改成垂直 | 道路、牆、路燈、行道樹、柱子 |
| 立體 | 水平八方位 × 往上斜、水平、往下斜，再加正上、正下，共 26 個方位 | 樓梯、斜坡、斜向的支架 |
| 自由 | 完全照視線方向，任意斜率都可以（例如 1:3 的緩坡） | 特殊角度；比較難瞄準 |

水平和立體模式會把方向「吸附」到最近的方位，所以視線稍微歪一點，蓋出來的線還是筆直的。

#### 自動反向：長柱子、從牆面往外長

如果線的第一步正好要鑽進「第一顆方塊貼著的那顆方塊」，就會自動反過來長：

- 看著**正下方的地面**放 → 往上長柱子（電線桿、路燈桿、橋墩）
- 看著**天花板**放 → 往下垂（吊燈的鍊子）
- 看著**牆面**放 → 從牆面往外長（雨遮、招牌支架）

#### 復原

快速建造選單裡的「復原上一次」可以收回最近 20 次快速建造：

- 只收回自動補上的方塊，**不包含自己放的第一顆**（第一顆用手打掉就好）
- 被覆蓋掉的方塊（例如水）會還原
- 復原紀錄只存在記憶體，離開世界後就會清空

### 常用物品

創造模式物品欄裡沒有、平常要用 `/give` 才拿得到的東西，按一下就放進背包。

| 分類 | 內容 |
| --- | --- |
| 建造輔助 | 結構方塊、結構空位、屏障、邊界、允許、拒絕、拼圖方塊 |
| 指令方塊 | 指令方塊、重複指令方塊、連鎖指令方塊、指令方塊礦車 |
| 特殊方塊 | 生怪磚、試煉生怪磚、寶庫、石化橡木半磚、霜冰 |
| 生怪蛋 | 鐵魔像、雪人、凋零怪、終界龍 |
| 光源方塊 | 用滑桿選亮度 0～15，會記住上次選的亮度 |
| 自訂清單 | 自己加的常用物品 |
| 輸入物品 ID | 輸入任何物品 ID 和數量就能拿；填上名稱就會加進自訂清單 |

要長期改清單內容，修改 `behavior_pack/scripts/catalog.js`，然後重新打包。

### 物品收藏

把染好色、印好圖案的旗幟、盾牌存起來，之後在哪裡都能拿出一份，不用重新染色印圖案。不只旗幟和盾牌，任何物品都可以收藏：地圖畫、寫好的書、改過名字的物品、附魔物品等。

1. 把要收藏的物品拿在手上
2. 主選單 → 物品收藏 → 收藏手上的物品，取個名字（例如「津蘭國旗」）
3. 之後在物品收藏的清單按一下，就會拿出一份；收藏本身不會減少

收藏時拿著幾個就存幾個：拿著 16 面旗幟收藏，之後每次就拿出 16 面。「管理」可以改名或刪除。

**做法：** 和結構方塊一樣。收藏時在你頭頂的高空暫時放一個箱子，把物品放進去存成結構，再把物品拿回你手上、把箱子移掉；拿取時把結構放回高空，從箱子裡拿出物品，再移掉箱子。所以旗幟的圖案、附魔、名稱等資料都會原封不動保留，而且收藏存在世界裡，換電腦或拔掉行為包都不會不見。

### 時間與天氣

| 按鈕 | 效果 |
| --- | --- |
| 切到半夜／切回白天 | 依照現在的時間顯示其中一個，一鍵切換。半夜（18000）最暗，適合看燈光效果 |
| 日出、白天、正午、日落、晚上、半夜 | 直接跳到這個時間 |
| 自訂時間 | 用滑桿選時間 |
| 時間流動 | 開關日夜循環（`doDayLightCycle`）。關掉就會固定在現在的時間 |
| 晴天、下雨、雷雨 | 切換天氣 |
| 天氣變化 | 開關天氣循環（`doWeatherCycle`） |

### 限制

- 快速建造不會複製箱子裡的物品、告示牌的文字、旗幟的圖案等「方塊實體」資料，只會複製方塊本身（要複製帶圖案的旗幟，用物品收藏）
- 快速建造不支援床（床是兩格，而且顏色存在方塊實體裡）
- 火把、按鈕、鐵軌等需要依附的方塊，快速建造補上的可能是懸空的，遇到方塊更新時可能會掉落
- 前方的區塊還沒載入（超出視野距離）時，快速建造會提早停下
- 物品收藏需要你頭頂上方有空位（通常是世界頂端的空氣），在很高的地方或蓋滿方塊的高空可能找不到空位
- 物品收藏或自訂清單裡放了 Asuka tech 的自製物品時，轉換程式 `convert.py` 會因為不知道怎麼處理而停下來，規則待決定（見 [docs/addon.md](../../docs/addon.md#53-asuka-工具包)）

## 開發

```
tools/asuka-toolkit/
├── behavior_pack/              行為包本體
│   ├── manifest.json
│   └── scripts/
│       ├── main.js             入口：事件、主選單、備用指令
│       ├── ui.js               共用：提示訊息、顯示表單
│       ├── quickbuild.js       快速建造
│       ├── line.js             快速建造的方向與座標計算（純計算）
│       ├── items.js            常用物品
│       ├── catalog.js          常用物品清單（純資料）
│       ├── favorites.js        物品收藏
│       ├── environment.js      時間與天氣
│       └── clock.js            遊戲時間的換算（純計算）
├── test/                       純計算部分的單元測試
├── build.py                    組包：正式版與開發版
└── release.json                正式版的版本號與內容雜湊
```

單元測試要 [Node.js](https://nodejs.org/) 22 以上，不需要安裝套件；組包要 Python 3，只用內建功能。

```bash
npm test --prefix tools/asuka-toolkit
```

想換開選單的物品：修改 `behavior_pack/scripts/main.js` 開頭的 `MENU_ITEM`，例如改成 `'minecraft:blaze_rod'`（烈焰棒），然後重新組包。
