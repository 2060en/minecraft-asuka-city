# 快速建造（Quick Build）

仿照以前「多玩我的世界盒子」的快速建造：開啟後，放下一顆方塊，就會朝你面向的方向自動補上後面幾格，不用輸入指令。可以設定數量、間隔（空幾格放一顆），也可以往斜線、往上下延伸。

> **狀態：開發中，還沒在遊戲裡實測。** 方向與座標的計算有單元測試，整個流程也用模擬的遊戲環境跑過，但還沒在真正的 Minecraft 裡試過。請先在世界的副本上測試，見下方「待驗證」。

## 符合可拔除原則

這是一個**只有腳本的行為包**，沒有新增任何自訂方塊、物品或實體：

- 放下的都是原版方塊，拔掉行為包之後，已經蓋好的東西完全不受影響
- 只用穩定版 Script API（`@minecraft/server` 2.1.0、`@minecraft/server-ui` 2.1.0），**不需要開啟任何實驗性功能**
- 唯一寫進存檔的資料是每位玩家的設定（數量、間隔等，幾十個字元），存在玩家資料裡；拔掉行為包後這筆資料不會被讀取，也不影響遊戲

因此符合 [`docs/technical.md`](../../docs/technical.md) 的「拔掉之後不影響體驗，放了錦上添花」。

## 安裝

1. 下載 [`dist/quick-build.mcpack`](dist/quick-build.mcpack)，雙擊檔案，Minecraft 會自動匯入
2. 先**複製一份世界**來測試（世界清單 → 編輯 → 複製世界）
3. 在副本的世界設定 → 行為包 → 找到「Quick Build 快速建造」→ 啟用
4. 確認「實驗性功能」裡的選項全部保持關閉。如果遊戲要求開啟「Beta API」，代表版本對不上，**不要開**，先回報問題
5. 進入世界，拿一根木棍右鍵，看到「快速建造」選單就成功了

需要 Minecraft 基岩版 1.21.100 以上（2025 年 8 月以後的版本）。

### 移除

世界設定 → 行為包 → 選擇「Quick Build 快速建造」→ 移除。已經蓋好的方塊都會留著。

## 使用方式

| 操作 | 效果 |
| --- | --- |
| 拿木棍右鍵 | 開選單：開關、調整設定、復原、使用說明 |
| 拿木棍**蹲下**右鍵 | 直接開關快速建造（不開選單） |
| 開啟後放一顆方塊 | 朝你面向的方向自動補上後面幾格 |
| `/qb:menu` | 開選單（備用，木棍不方便時用） |
| `/qb:undo` | 復原上一次快速建造（備用） |

每次進入世界時，快速建造都是**關閉**的，避免一進去就不小心長出一整排。設定（數量、間隔等）會記住。

後面補上的方塊和第一顆完全一樣，包括朝向：樓梯、原木、半磚（上半／下半）、鐵軌的方向都會照抄。門、高草、向日葵這種兩格高的方塊，上半部會一起複製。

### 設定項目

| 項目 | 說明 | 預設 |
| --- | --- | --- |
| 數量 | 自動補上幾顆，不含自己放的第一顆（1～1000） | 20 |
| 間隔 | 每顆之間空幾格（0～256）。0 是連續一整排；3 是「放一顆、空三格、再放一顆」 | 0 |
| 方向 | 見下方「方向模式」 | 水平 |
| 可以覆蓋哪些方塊 | 只放空氣／空氣和液體（水、岩漿）／全部覆蓋 | 空氣和液體 |
| 遇到放不下的位置 | 停下來／跳過，繼續往後放 | 停下來 |

「全部覆蓋」也不會蓋掉基岩和箱子等容器，因為容器裡的東西沒辦法復原。

### 方向模式

| 模式 | 方向 | 適合 |
| --- | --- | --- |
| 水平（預設） | 東西南北加四個斜角，共八個方位。抬頭或低頭超過 75° 時改成垂直 | 道路、牆、路燈、行道樹、柱子 |
| 立體 | 水平八方位 × 往上斜、水平、往下斜，再加正上、正下，共 26 個方位 | 樓梯、斜坡、斜向的支架 |
| 自由 | 完全照視線方向，任意斜率都可以（例如 1:3 的緩坡） | 特殊角度；比較難瞄準 |

水平和立體模式會把方向「吸附」到最近的方位，所以視線稍微歪一點，蓋出來的線還是筆直的。

### 自動反向：長柱子、從牆面往外長

如果線的第一步正好要鑽進「第一顆方塊貼著的那顆方塊」，就會自動反過來長：

- 看著**正下方的地面**放 → 往上長柱子（電線桿、路燈桿、橋墩）
- 看著**天花板**放 → 往下垂（吊燈的鍊子）
- 看著**牆面**放 → 從牆面往外長（雨遮、招牌支架）

### 復原

選單裡的「復原上一次」可以收回最近 20 次快速建造：

- 只收回自動補上的方塊，**不包含自己放的第一顆**（第一顆用手打掉就好）
- 被覆蓋掉的方塊（例如水）會還原
- 復原紀錄只存在記憶體，離開世界後就會清空

## 限制

- 箱子裡的物品、告示牌的文字、旗幟的圖案等「方塊實體」資料不會複製，只會複製方塊本身
- 不支援床（床是兩格、而且顏色存在方塊實體裡）
- 火把、按鈕、鐵軌等需要依附的方塊，後面補上的可能是懸空的，遇到方塊更新時可能會掉落
- 前方的區塊還沒載入（超出視野距離）時會提早停下
- 補上的方塊不會觸發「玩家放置方塊」的效果，例如不會發出放置音效

## 待驗證

還沒在遊戲裡實測，以下項目要在世界副本上確認：

- [ ] 行為包可以匯入、啟用，而且不會要求開啟實驗性功能
- [ ] 拿木棍對著空氣右鍵、對著方塊右鍵，都能開選單
- [ ] 蹲下拿木棍右鍵可以開關
- [ ] 水平、立體、自由三種方向模式的手感，水平模式的 75° 門檻是否合適
- [ ] 看著地面放方塊時，會往上長柱子（需要遊戲在放方塊前觸發「右鍵點方塊」事件）
- [ ] 在水裡放半磚、柵欄等方塊時，後面補上的會不會保持含水
- [ ] 復原是否正確
- [ ] 一次補 1000 顆時會不會卡頓

## 開發

```
tools/quick-build/
├── behavior_pack/          行為包本體
│   ├── manifest.json
│   └── scripts/
│       ├── main.js         事件、選單、放方塊、復原
│       └── line.js         方向吸附與座標計算（純計算，可以在電腦上測試）
├── test/line.test.js       line.js 的單元測試
├── build.js                打包成 dist/quick-build.mcpack
└── dist/quick-build.mcpack 打包好的檔案，雙擊即可匯入
```

需要 [Node.js](https://nodejs.org/) 22 以上，不需要安裝任何套件：

```
cd tools/quick-build
npm test        # 跑單元測試
npm run build   # 重新打包 dist/quick-build.mcpack
```

修改程式後記得重新打包，並把新的 `.mcpack` 一起 commit。

開發時可以把 `behavior_pack` 資料夾直接複製到遊戲的 `development_behavior_packs` 資料夾（GDK 版的位置待確認，可能在 `%APPDATA%\Minecraft Bedrock\Users\Shared\games\com.mojang\development_behavior_packs`），改完程式在遊戲裡輸入 `/reload` 就能套用，不用重新匯入。

### 想換開選單的物品

修改 `behavior_pack/scripts/main.js` 開頭的 `MENU_ITEM`，例如改成 `'minecraft:blaze_rod'`（烈焰棒），然後重新打包。
