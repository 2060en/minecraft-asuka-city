# 新玩家序章

記錄新玩家第一次加入世界時的出生點與開場橋段。

> 「待決定」的項目還在考慮中，Claude 的提案整理在最後的[待決定事項](#待決定事項)。

---

## 構想

| 項目 | 內容 | 狀態 |
| --- | --- | --- |
| 目的 | 新玩家加入世界時的出生點，用一段小橋段介紹這個世界，像許多遊戲的序章 | 已定 |
| 形式 | 介紹房間或飛機，見下方 | 待決定 |

### 構想一：介紹房間

新玩家出生在一個房間裡，房間內有基礎介紹、開場白等。

### 構想二：飛機

1. 在空中造一架飛機，新玩家出生在飛機上
2. 透過指令方塊輸出文字，介紹一些資訊
3. 玩家按下按鈕（或用其他方式）後，飛機降落，把玩家傳送到機場（AKQ）的登機門
4. 準備入境

## 待決定事項

- [ ] **採用飛機方案，把介紹房間併進去**，Claude 的提案：
  - 飛機貼合本國「東北亞居中者、國際樞紐」的定位，AKQ 與 Asuka Air 也都已經有了
  - 入境本身就是介紹國家的好時機
  - 原本的介紹房間可以變成入境大廳的旅客服務中心
- [ ] **流程**，Claude 的提案：
  1. 出生在 Asuka Air 的機艙裡，機型用機隊中的 787-8 或 A330-900（見[機隊](world/flight-schedule.md#機隊與排班)）
  2. 機長廣播與螢幕字幕介紹本國：國名、首都、人口、語言、貨幣、時區、靠左行駛
  3. 玩家按下「繫好安全帶」的按鈕後播放降落橋段：黑幕、引擎與落地的音效，傳送到 AKQ 的登機門，再淡入
  4. 入境審查：移民官 NPC 詢問入境目的（觀光、商務、定居），選項同時決定遊戲模式與權限，例如觀光是冒險模式、只能參觀
  5. 入境大廳的旅客服務中心：介紹、全島地圖（用 Image map 把 uNmINeD 鳥瞰圖做成地圖畫）、各地的指引
- [ ] **飛機的位置**：
  - 放在 AKQ 進場航線上的高空：窗外就是真的列島與市區，但地面上的人看得到一架停在空中的飛機
  - 放在看不到的地方：窗外景色用地圖畫做，不會破壞地面的沉浸感，但看不到真的世界
- [ ] **實作方式**，Claude 的提案（都是遊戲內建功能，符合[原汁原味](technical.md#2-建造原則原汁原味)的原則）：
  - 判斷新玩家：用 `/tag` 標記看過序章的玩家，沒有標記的玩家加入時送進機艙
  - 常駐區域：指令方塊只在已載入的區塊運作，機艙與入境大廳要用 `/tickingarea` 設為常駐區域（每個世界最多 10 個）
  - 字幕的時間軸：指令方塊可以設定「延遲刻數」，一排連鎖指令方塊就能依序播放字幕與音效
  - 降落演出：`/camera` 的 fade 做黑幕；free 模式加上 ease 可以做運鏡，例如鏡頭掠過市區、沿著跑道進場，就是一段短影片
  - 演出期間：`/inputpermission` 鎖住移動，`/hud` 隱藏介面
  - 對話：開啟作弊的世界可以 `/summon npc`，NPC 的對話框可以加按鈕、執行指令，空服員與移民官都能用
  - 序章期間用冒險模式，避免新玩家破壞機艙
  - 世界的預設遊戲模式與玩家權限要另外設定：目前的世界是創造模式
  - 先在世界的副本上測試（見[技術文檔](technical.md#實驗性功能事件)）
