## 鐵路

### 縱貫鐵路

- **路線**：從主島西南端的港口出發，經 Asuka 中央車站、第二大都市，沿北部的西北側海岸北上，最後轉入山間盆地（富良野）為終點
- **營運模式**：大部分列車只行駛 Asuka 以北，也就是中央車站經第二大都市到北部的區間；只有部分班次越過 Asuka 繼續往南，開到南方離島
- **車輛**：島內列車規模不大，參考北海道，四節車廂一組

先例：台鐵南迴線也是只有部分班次越過枋寮繼續往台東開。

### 黒潮特快

- **名稱**：「黒潮特快」是作者的通稱；列車等級是特急，正式的列車名待決定
- **路線**：在 Asuka 中央車站的地下月台直接接入海底隧道，不經過南方離島
  - 往南：奄美 → 名護 → 那霸 → 宮古 → 石垣
  - 往北：屋久島 → 種子島 → 鹿兒島
- **車輛**：以台鐵 EMU3000 為原型，採標準軌（1435 公釐），時速 180～200 km/h。先例：日立在英國的標準軌城際列車（Class 800 系列）就以 200 km/h 營運
- **Asuka 中央車站**：地下月台，是本國唯一的黒潮特快車站
- **與新幹線**：不和九州新幹線直通
- **通關**：封閉式過境列車，在本國上下車的旅客搭國際車廂，由移民官在車上查驗，見[世界觀總覽](overview.md#黒潮特快)

### Asuka 中央車站

位於総督府正對面，規模不小。

| 路線 | 月台 |
| --- | --- |
| 縱貫鐵路 | 4 個月台；其中 2 個月台的軌道只鋪到中央車站為止，供北行列車在這裡始發、折返 |
| 黒潮特快 | 地下月台 |
| 地鐵藍線 | 有 |
| 地鐵綠線（單軌） | 有 |

量體檢查：縱貫鐵路 4 個月台，在 `scale.md` 的上限（哥本哈根中央車站、仙台站的等級）以內。

## 首都地鐵

| 路線 | 型式 | 走向 | 狀態 |
| --- | --- | --- | --- |
| 綠線 | 單軌 | 東西向。從機場往西，沿市區最熱鬧的大街（路名待定）貫穿 CBD，開到西北角的棒球場 | 已建成 |
| 橘線 | 地鐵 | 南北向，偏西。北到港區海邊，南到南邊海灘 | 規劃中 |
| 藍線 | 地鐵 | 南北向，偏東。北到港區海邊，南到東南方的湖區；經過中央車站 | 規劃中 |
| 紫線 | 地鐵 | 片假名「コ」字形，把市區圈起來 | 規劃中 |

> 橘線、藍線的東西位置依規劃圖判讀。
> 綠線在規劃圖上是用青色的筆畫的，實際蓋的是綠線。

- 量體檢查：4 條在 `scale.md` 的上限（約 3～4 條）以內；哥本哈根同樣是 4 條，其中一條是環狀線
- 綠線的先例：沖繩的單軌電車（ゆいレール）從那霸機場出發，架在市區幹道上方
- 紫線的先例：台北捷運環狀線第一階段也是半圈的弧形

| 港口 | 功能 |
| --- | --- |

| 機場 | 內容 | 狀態 |
| --- | --- | --- |
| Asuka City 機場（AKQ） | 緊鄰市區東側，見下方 | 已建成 |
| 國內線專用航廈 | 在 AKQ 另建一個極小的空間，供國內線專用；國內線班次太少，占用主航廈太浪費 | 已定，未建 |

### Asuka City 機場（AKQ）

| 項目 | 內容 |
| --- | --- |
| 跑道 | 一條，遊戲中約 1000 格，設定上 3000 公尺 |
| 航廈 | 一座 |
| 機坪 | 15 個，其中 8 個有空橋 |
| 機場等級 | 4E（可起降 777、787、A350 等級的廣體機） |
| 年旅客量目標 | 約 500～1000 萬人次，基地航空公司佔 30～40% |
| 尖峰容量 | 單跑道約每小時 20～25 架次 |
| 基地航空公司 | Asuka Air（IS），航班見 [AKQ 航班表](flight-schedule.md) |

> 筆記寫的是「4E 消防等級」，但 4E 是 ICAO 的機場參考代碼（跑道 1800 公尺以上、翼展 52～65 公尺）。消防等級另外分級，起降 777-300ER、A350-900 需要第 9 類。

### 航廈出發層

由左到右：

| 位置 | 設施 |
| --- | --- |
| 最左側 | 巴士總站入口 |
| 第 1 櫃台島 | 星空聯盟 |
| 第 2 櫃台島 | 寰宇一家 |
| 第 3 櫃台島 | IS、JX |
| 第 4 櫃台島 | 拆除，改為自助機台 |
| 第 4、5 櫃台島之間 | 國際線出發管制區入口 |
| 第 5 櫃台島 | 拆除，改為自助機台 |
| 第 6 櫃台島 | 天合聯盟與其他，彈性共用 |
| 第 7 櫃台島 | 廉航或其他，彈性共用 |

國內線移到專用航廈，主航廈不設國內線設施。

- 貴賓從出發層前側的門直接進來，不用上下樓，走五步就到櫃台
- 樓下原本的空間改為接機專用（本來就是抵達層）
- 大廳不設獨立的貴賓服務空間，另外設類似環亞機場服務的一條龍貴賓服務，貴賓不用進大廳

### 區域機場

- 南部機場以下地島機場為範本，幾乎照抄，但依宏觀尺度縮小：跑道遊戲中約 500 格，設定上 1500～2000 公尺等級，起降 ATR72，偶爾 A320
- 北部機場（是否興建還在考慮）：Keep 筆記中以皇后鎮機場（ZQN，再小一點）、旭川機場（AKJ）為範本
- 國內航線只飛 AKQ，形成支線接駁樞紐的結構
- 南北小機場原則上不排每日定期國際線，只接受季節包機。例如濟州航空、台灣虎航飛北部的滑雪包機；HK Express、星宇航空飛南部的海灘包機

## 待決定事項

- [ ] **尖峰時段的列車編組**：第二大都市是 Asuka 的通勤城，四節一組在尖峰時段可能不夠。建議尖峰時段兩組連掛成八節（先例：基隆到台北的通勤列車多為八節以上）
- [ ] **縱貫鐵路的軌距**：建議沿用日本時代的 1067 公釐窄軌（台灣、日本的傳統鐵路都是），和標準軌的黒潮特快分開
- [ ] **跨海到南方離島的鐵路**：黒潮特快不經過南方離島，所以這段跨海鐵路是為縱貫鐵路自己蓋的。人口少的觀光島嶼蓋跨海鐵路有先例：德國敘爾特島靠一條約 11 公里的鐵路堤連接本土，島上常住人口不到 2 萬，以觀光為主
- [ ] **綠線大街的路名**
- [ ] **國內線設施的形式與規模**，Claude 的建議：
  - 形式：不另蓋一座航廈，改在主航廈一端加一個一樓的附屬候機區，有自己的報到櫃台、安檢與候機室，動線和國際線分開，但和主航廈共用車道、巴士總站與單軌站。國內線一天只有 8～16 個架次，需要分開的是通關動線，不是整棟建築。先例：下地島機場的航廈是同一棟分國內、國際區；熊本機場 2023 年啟用的新航廈把國內、國際線合在同一棟；那霸機場 2019 年蓋了連結航廈，把國內、國際兩棟接起來
  - 規模：早上 07:10～07:50 南北兩架 ATR72 會同時在 AKQ，所以至少 2 個機坪，另留 1 個給延誤或備用；徒步登機，不設空橋，也不占主航廈的 15 個機坪。候機室以同時約 110 人估算（兩架 ATR72、載客率八成）。年旅客量只開南部約 16 萬人次，加上北部約 33 萬人次（以 70 席、載客率八成估算）
  - 轉機動線：國際轉國內的旅客在主航廈入境、提領行李、通關後，到國內線航廈重新託運；可在主航廈抵達層出口設轉國內線的行李託運櫃台。先例：在日本國際轉國內線，也要在第一個入境的機場通關、提領行李再重新託運
