## 設計原則：合理性與特色

設定要經得起推敲，但也允許兩種「不合理」：

1. **個人滿足**：畢竟是在玩遊戲
2. **地方特色**：每個地方都有獨特之處，有些特色是必要的

特色可以有，但不能破壞基本的量體與比例。以下是不能接受的例子：

- 一個沖繩大小的小國，經濟規模全球第一
- 全國人口不到 500 萬、都市人口不到 200 萬、鐵路只有幾條而且不長，卻蓋了一座新宿等級的中央車站

### 國際地位：東北亞的居中者

這是這個世界的立足之本。

- 日本、韓國、台灣、中國之間彼此有歷史恩怨，需要一個高度發達的小國居中
- 政策、人才、企業經由這裡「過水」，就能彼此合作
- 角色類似香港，但是東北亞的版本

國內的鄉間則以觀光為主：北部是雪國與山岳，南部島嶼是珊瑚礁海灘度假地。

### 同時承認兩岸

本國同時承認中華民國與中華人民共和國，兩國都在 Asuka City 設有大使館，而且兩國的大使館相鄰。

這是作者的特權：兩邊都不敢得罪本國，因為得罪的話，作者會把世界關掉。

現實中沒有成功的先例：1989 年台灣推動彈性外交，和格瑞那達、賴比瑞亞、貝里斯建交，北京隨即和這三國斷交；2004 年萬那杜總理想同時承認台灣，幾週內就被國會倒閣。

屬於刻意保留的特色，世界內不另做解釋，不再追究。

### 使館

市區土地有限，使館依區域集中成五座「使館園區」。每座園區有一道共同的圍牆，各國有自己的側翼或小樓，共用大廳，先例是柏林的北歐五國使館園區。這樣各國的主權與保全都說得通，美國使館也能有自己的獨立出入口。

| 園區 | 成員 |
| --- | --- |
| 歐洲 | 歐盟代表團與歐洲各國，包含已脫歐的英國，以及瑞士、挪威 |
| 北美 | 美國、加拿大、墨西哥 |
| 東亞 | 日本、韓國、中華民國、中華人民共和國、蒙古；不設北韓使館 |
| 亞太 | 東南亞、南亞、中東、澳洲、紐西蘭，以及亞太經合會成員俄羅斯 |
| 非洲與南美 | 非洲與中南美各國 |

- 東亞園區由本國政府出資興建，宿敵同在一個屋簷下，象徵居中者的角色；中華民國與中華人民共和國的使館在這裡相鄰
- 很多國家由駐東京的大使兼任，不設常駐使館

### 經濟

非常富裕，原因有二：

1. 居中者的特殊地位
2. 國家主權基金非常會投資（總部設在 CBD）

「富裕」指的是人均，不是經濟總量。以 150 萬人、人均 10 萬美元估算，經濟總量約 1500 億美元，大約是日本的 3～4%，不會出現「小國經濟規模全球第一」的不合理狀況。

### 為什麼是獨立國家

居中者的定位與新加坡式的政體，都以獨立為前提：日本的一個縣無法在中日、日韓之間居中，也不可能有自己的一黨獨大政體。

代價是需要建置的國家機關比較多，故事也要更充實。

### 地理位置：取代寶島的位置

本國直接取代現實中寶島、小寶島的位置：奄美大島西北方，吐噶喇列島的南端，約北緯 29 度。架空世界中沒有寶島、小寶島。

- 想要北部有雪、南部有海灘，放得太南邊會很奇怪
- 北邊的吐噶喇列島其他島嶼、南邊的奄美都是日本領土。原本擔心這樣看起來像把日本國土切開，但北緯 30 度分離線提供了歷史依據：這一帶在二戰後本來就曾和日本分離（見[歷史](#歷史)）

### 黑潮特快

已經通車的跳島鐵路，沿著琉球島鏈把各島串連起來，從那霸經過本國，一路開往九州。這是把國家放在島鏈附近的主要原因。

- 路線：在 Asuka 中央車站的地下月台直接接入海底隧道。往南經奄美、名護、那霸、宮古到石垣；往北經屋久島、種子島到鹿兒島。不經過本國的南方離島
- 車輛：以台鐵 EMU3000 為原型，採標準軌，時速 180～200 km/h
- 詳見[交通](transport.md#黑潮特快)

工程難度不追究，屬於刻意保留的特色。

通關方式：封閉式過境列車。從那霸開往九州、不在本國上下車的旅客不用查驗；在本國上下車的旅客，由移民官在行駛途中於車上個別查驗。過境的先例是奧地利的列車穿越德國領土時的過境列車；車上查驗的先例是芬蘭與俄羅斯之間的 Allegro 列車。在本國上下車的旅客只能搭指定的國際車廂，移民官只查這幾節，過境旅客不會被打擾。這樣兼顧日本國內旅客的便利與本國的中立。

## 氣候

像是縮小版的日本氣候：

| 地區 | 氣候 | 參考 |
| --- | --- | --- |
| 北部高山與山間盆地 | 雪國，冬季穩定積雪 | 北海道、瑞士 |
| 北部平地 | 不會經常下雪 | — |
| 中部（都市） | 一般的海洋性氣候 | — |
| 南部 | 海島氣候 | 沖繩 |

只有高山與山間盆地是雪國。北部山地很高、很陡峭（像台灣的山），加上冬季的風向與水氣才會下雪。現實中也有先例：屋久島位在北緯 30 度，海岸是亞熱帶，將近 2000 公尺的山頂冬季會積雪；台灣的合歡山也一樣。

## 歷史與人文

### 民族

移民社會，日本人最多，華人次之。

明治以前島上已有島民，語言與文化屬琉球、奄美系。明治時期大量移民進來後，才成為以日本移民為主的社會，類似北海道。島民語言的地名多半在明治時期套上讀音相近的漢字，例如 Asuka（飛鳥），見[命名](naming.md)。

### 語言

日語為主，英語為輔。

- 日語：大多數國民的母語，也是行政與日常生活的主要語言。國家機關沿用日本的叫法，例如内閣府、国会、最高裁判所。日文漢字源自古代中文，說中文的人也大致看得懂，有利於居中者的定位
- 英語：英國託管時期的行政語言，獨立後退居輔助。先例是馬來西亞：1957 年獨立，1967 年起以馬來語為唯一的官方語言，英語至今仍廣泛使用
- 招牌：日英雙語（像日本的車站、香港的路牌），舊市區以日文為主。建造上，英文比較好做成招牌與裝飾，也比較簡潔
- 普通法不一定要用英語運作，香港的法院就同時使用中文與英文

原本設定為英語為主，後來改為日語為主。

### 宗教

- 沒有主要宗教，奉行唯物主義：這是國家帶動形成的社會風氣
- 宗教場所的規模都很小，不會有大型宗教設施
- 日本時代的小神社、英國時代的小教堂，保留為歷史遺跡

神社都很小的原因：英國託管時期比照美軍在日本發布的「神道指令」（1945），廢除國家神道、停止公費補助，神社因此縮小。獨立後，政府再帶動唯物、務實的風氣。

日本人與華人社會本來就是世界上宗教性最低的族群之一，「沒有主要宗教」很合理。

### 歷史

| 時期 | 事件 |
| --- | --- |
| 明治以前 | 島民居住，語言與文化屬琉球、奄美系 |
| 明治時期 | 日本大量開發 Asuka City，奠定現在的基礎建設 |
| 二戰以前 | 日本統治，屬於「外地」（類似台灣） |
| 1946 年 | GHQ 把北緯 30 度以南的南西諸島從日本的行政權中分離。美國接管琉球與奄美；本國同樣在這條線以南，因為戰後談判時英國也想分一杯羹，改由英國託管 |
| 1952～1972 年 | 吐噶喇列島（1952）、奄美（1953）、沖繩（1972）陸續歸還日本；本國沒有歸還，而是走向獨立 |
| 1960 年代中期 | 獨立，時間與新加坡（1965 年）幾乎同步，發展路線也類似新加坡 |
| 1960～70 年代 | 貨櫃化，主要港口從第二大都市轉移到 Asuka City（見[地理](geography.md#中北部第二大都市)） |

英國託管有現實的影子：二戰後英國確實參與了日本的佔領，英聯邦佔領軍曾駐紮在廣島、吳一帶。北緯 30 度分離線（GHQ 1946 年的 SCAPIN-677）也是真實存在的。

### 明治時期留下的遺產

- 舊市區：靠近港口，有許多巴洛克建築
- 舊英國領事館：日本統治時期英國設在港口舊市區的領事館，現為歷史建築（像淡水紅毛城、打狗英國領事館）
- 舊帝國大學
- 皇居離宮：規模不大，過去天皇來度假休憩的地方，氛圍像京都御苑。屬於京都御所式的建築，離市中心有一段距離，不作為政治中心；現為國賓館，見下方的政治中心

### 政治中心

| 建築 | 經歷 | 現在 |
| --- | --- | --- |
| 總督府 | 日本外地時期建成的總督府（像台灣總督府），英國託管時期沿用 | 行政中心，總統與總理在這裡辦公（像新加坡的 Istana） |
| 内閣府 | 獨立後興建的政府大樓 | 位於總督府後方，和總督府組成一個園區；內閣與主要部會在這裡辦公 |
| 皇居離宮 | 明治時期天皇度假休憩的離宮 | 國賓館兼中立會談的場地 |

總督府正對車站、白宮樣式，靠近港口。殖民城市的政治中心常在港邊，因為統治者從海上來，最先發展的就是港口與海關：新加坡的市政區在新加坡河口，香港的政府山緊鄰維多利亞港，橫濱的神奈川縣廳也在港邊。這也和「舊市區靠近港口」的設定吻合。

總督府與後方的内閣府組成一個園區，舊建築當門面、新大樓辦公。先例是日本的首相官邸：1929 年的舊官邸改為首相公邸，和 2002 年的新官邸在同一個街區。

量體參考：150 萬人口的國家，中央部會本部的人員約兩三千人，大約是一棟 20 層左右的政府大樓；國稅局、警察總部、情報局等已經各自有建築。

離宮離市中心有一段距離，不適合當政治中心，但隱密、好維安，適合招待外賓與舉行會談。先例：京都迎賓館位於京都御苑內、赤坂離宮改為迎賓館、美國的大衛營。

## 法律與規則

- 法律體系：英美法（普通法）。日本外地時期使用日本法，英國託管時期改為英美法，獨立後沿用，和香港的歷程相似
- 右駕（方向盤在右、靠左行駛，與日本相同）
- 目前沒有其他特別的法律
- 作者說了算，但會顧及合理性
- 法院沿用日本的叫法：最高裁判所、高等裁判所、地方裁判所
- 最高裁判所的建築是日本時代的高等法院，英國託管時期成為最高法院，獨立後沿用（先例：台北的司法大廈原本是台灣總督府高等法院）

英美法也支撐了居中者的定位：國際商業合約、金融與仲裁大多習慣使用英國法，這是香港、新加坡能成為國際金融與仲裁中心的重要原因之一。中日韓台的企業在本國簽約、訴訟、仲裁，使用英美法最順理成章。

### 空軍
