## 設計原則：合理性與特色

設定要經得起推敲，但也允許兩種「不合理」：

1. **個人滿足**：畢竟是在玩遊戲
2. **地方特色**：每個地方都有獨特之處，有些特色是必要的

特色可以有，但不能破壞基本的量體與比例。以下是不能接受的例子：

- 一個沖繩大小的小國，經濟規模全球第一
- 全國人口不到 500 萬、都市人口不到 200 萬、鐵路只有幾條而且不長，卻蓋了一座新宿等級的中央車站

### 國際地位：東北亞的居中者

這是這個世界的立足之本。

- 日本、韓國、台灣、中國之間彼此有歷史恩怨，需要一個高度發達的小國居中
- 政策、人才、企業經由這裡「過水」，就能彼此合作
- 角色類似香港，但是東北亞的版本

國內的鄉間則以觀光為主：北部是雪國與山岳，南部島嶼是珊瑚礁海灘度假地。

### 黑潮特快

構想中的海底鐵路隧道，從那霸經過本國，一路開往九州。這是想把國家放在沖繩島鏈上的主要原因。

### 為什麼在「獨立」與「日本的一個縣」之間搖擺

獨立小國需要建置的國家機關很多，有點麻煩；故事也要更充實才撐得起來。

### 為什麼地理位置還沒定

- 想要北部下雪、南部有海灘，放得太南邊會很奇怪
- 放得太北邊，又很像日本的一個縣；南北兩邊都是日本領土，獨立成一國會怪怪的

目前的說法：北部山地很高、很陡峭（像台灣的山），再加上特殊的風向與水氣，冬季才會下雪。

構想中的解法：和島鏈並排，例如位在奄美大島西側，避免看起來像是把日本國土切開。島鏈上的島嶼並排或分岔並不奇怪。

## 歷史與人文

### 民族

移民社會，日本人最多，華人次之。

### 語言

待決定。日語比較合理；但以這個國家的國際地位，也可以像新加坡一樣使用英語。英文也比較好建造裝飾，比較簡潔。

### 歷史

| 時期 | 事件 |
| --- | --- |
| 明治時期 | 日本大量開發 Asuka City，奠定現在的基礎建設 |
| 二戰以前 | 日本統治 |
| 二戰之後 | 獨立，發展路線類似新加坡 |

### 明治時期留下的遺產

- 舊市區：靠近港口，有許多巴洛克建築
- 舊帝國大學
- 皇居離宮：規模不大，過去天皇來度假休憩的地方，氛圍像京都御苑
