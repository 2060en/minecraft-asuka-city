## 品牌與店家一覽

目前出現過的品牌與店家，分成三大類（作者 2026-11-09 定的分法）：

| 類 | 內容 | 例子 |
| --- | --- | --- |
| 一、現實進駐 | 現實中有的品牌，直接進駐本國 | 便利商店御三家、三家外國銀行、麥當勞 |
| 二、現實原型改編 | 以現實的品牌為原型，作者改過 | Spoton、TakoEats |
| 三、完全虛構 | 作者自己虛構的 | Asuka Inc. |

二和三的界線（已定，2026-11-09）：名稱、logo 或品牌色照某一個現實品牌改的放二；只參考業態或定位、品牌本身是新的放三。

### 一、現實進駐

第一類的細節（經營方式、定位等）作者交由 Claude 決定，遇到和既有設定衝突的再討論（作者 2026-11-09）。

- 經營方式的預設（已定，作者交由 Claude 決定）：由品牌的總部或它的子公司直營，跟[便利商店](#便利商店)御三家一樣；Asuka Inc. 拿代理權經營的另外標出來。現實中兩種都很常見：日本的 Starbucks 現在由美國總部全額持股，台灣的星巴克則由統一企業合資經營
- 單店或地方小連鎖的預設（已定，作者交由 Claude 決定，2026-11-09）：在本國開分店，很多是它的第一家海外店。說得通的理由：本國用日圓、以日語為主、就在九州南邊，對日本的店來說，到本國開店跟到沖繩開店差不多。現實中在沖繩起家或已經開在沖繩的店（例如ポーたま、甘味処 万丸），這個世界裡本來就在本國，本島的是分店
- 作者從 Google 地圖圖釘挑的店（2026-11-09）：主要是連鎖店；獨立小店（大多是餐廳）只挑了一定要放的，沒挑到的不代表否決，留在[備用餐廳清單](#備用餐廳清單)

## 汽車

日本大部分的車廠都有，人民開什麼車不受限制，大致跟日本一樣（右駕、靠左行駛，見[世界觀總覽](overview.md#法律與規則)）。跟日本不同的有三點（作者 2026-11-09）。

| 項目 | 設定 | 狀態 |
| --- | --- | --- |
| 車廠 | 日本大部分的車廠都有：Toyota、Honda、Nissan、Mazda、Subaru、Suzuki、Daihatsu、Mitsubishi | 已定 |
| 開什麼車 | 不限制，大致跟日本一樣 | 已定 |
| Tesla | 市占率很高 | 已定 |
| Lexus | 幾乎沒人開：曾經有一位教授爆發學術醜聞，他開的是 Lexus，品牌被牽連，大家都不想開。刻意的特色 | 已定 |
| 改裝 | 不流行 JDM。改排氣管、改競速這類的改裝，政府管得很嚴；戶外類的改裝比較寬容。刻意的特色 | 已定 |
| 經銷 | 照預設由車廠的子公司經營 | 已定（作者交由 Claude 決定） |
| Lexus 的經銷 | 只剩首都一家據點，Toyota 本身不受影響；二手 Lexus 很便宜 | 已定（作者交由 Claude 決定） |

- Tesla 市占率高的先例：挪威是有主權基金的富裕小國，2024 年新車將近九成是電動車，最暢銷的車是 Tesla Model Y；香港近年新的私家車也有一半以上是電動車。本國一樣富裕，電力有核電廠，島上的距離也短，電動車很合用
- 品牌被一個人牽連的先例：2025 年 Tesla 在歐洲的銷量大跌，原因之一是 Musk 的政治立場讓品牌被牽連；英國的 Burberry 格紋在 2000 年代被貼上「chav」（小混混）的標籤，品牌一度受傷。小國的新聞圈小，一則醜聞天天播，更容易變成全民的梗
- 改裝管很嚴的先例：新加坡的陸路交通管理局（LTA）對改裝管得很嚴，改排氣管、改引擎都要審核，違規會被罰；日本的車検也會擋不合規定的改裝
- 戶外改裝比較寬容說得通：管制的重點是噪音、排氣和行車安全，車頂架、車頂帳篷、拖車鉤多半是外掛的，不影響這些。北部是雪國和山岳，戶外活動盛行，mont-bell、The North Face 也都有開
