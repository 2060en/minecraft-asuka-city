## 待決定事項

- [ ] **本土的商業集團**：本國有沒有大型的商業集團，超市與便利商店由誰經營。Claude 提的方向（還不是提案）：日本外地與英國託管兩個時期，可以各留下一種本土集團，一種是日本時代的商社留下來的（建造清單想蓋的大阪商船建築可以當痕跡），一種是英國託管時期的洋行（像香港的怡和、太古）。現實中小型貿易樞紐的零售常握在少數集團手裡：香港的怡和（惠康、萬寧）與長和（百佳、屈臣氏），新加坡的 NTUC FairPrice（工會的合作社），紐西蘭超市的 Foodstuffs 與 Woolworths
- [ ] **Asuka Inc. 在商業上的角色**：零售也是它的，還是交給其他集團，Asuka Inc. 只當購物中心的房東
- [ ] **消費稅**：菜單標含稅價，等於默認有消費稅，但名稱和稅率還沒定
- [ ] **便利商店少了菸**：日本平均一家便利商店一年賣約 4,300 萬日圓的菸（[財務省 2016 年的調查](https://www.mof.go.jp/policy/tab_salt/reference/tab_stat/result2016.html)），約是營業額的兩成。本國的便利商店要靠其他東西補，例如鮮食、咖啡、繳費、包裹
- [ ] **量體**：一個品牌在本島開幾家店合理，對照[量體基準](../scale.md)
- [ ] **建造清單的「食物清」**：待確認是哪個品牌
