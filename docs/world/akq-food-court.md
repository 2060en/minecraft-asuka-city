# AKQ 美食街

記錄 AKQ 國際航廈 3F 美食街（內部叫二樓，地板 Y84）各店的品牌、菜單，以及可以直接照打的告示牌文字。建築的現況見[交通](transport.md#樓層與動線)。

作者 2026-11-09～10 和 Claude 逐家討論定案，座標對照 11/9 的存檔。

> 還沒定的項目整理在最後的[待決定事項](#待決定事項)。

## 共用原則（已定）

- 價格照日本現在的價格，不另外加機場的價錢；寫「¥」加含稅價
- 日文為主、英文為輔，跟航廈其他告示牌一樣
- 現實的店照現實的品項和價格；自創的店另外想品牌故事
- 小店、小餐廳的店名不用[命名素材](naming.md#命名素材)，素材大部分留給比較重要的東西（作者 2026-11-09）
- 菜單用告示牌做，不用 Image map 的地圖畫（作者 2026-11-10），寬度與排法見[告示牌](#告示牌)
- 每間店的品牌故事和完整菜單都留在這份文件。遊戲裡的菜單告示牌，作者故意沒有全放（放太滿很亂），沒放的品項也不刪（作者 2026-11-10）

## 告示牌

### 一行的寬度

用遊戲本身的字型圖量的：遊戲資料夾 `data/resource_packs/vanilla/__brarchive/font.brarchive` 裡的 `default8.png`（英文）和 `glyph_XX.png`（日文、漢字等）。再用存檔裡作者寫好、4 行全滿的告示牌校正：這種告示牌如果有一行自動換行，最後一行會被擠出去，所以上面的每一行都放得下。

| 字 | 每個字的寬度（含字距） |
| --- | --- |
| 英文、數字 | 大部分 6 像素；I、t 是 4，l 是 3，i 是 2，空白 4 |
| 假名 | 約 7.5～10.5 像素 |
| 漢字 | 約 12～12.75 像素，比假名寬很多 |
| 「¥」 | 半形約 6.75，全形「￥」約 9.75 |

- 日文和漢字的算法：16 像素的字型圖縮成 0.75 倍，每字是 0.75 ×（字的實際寬度＋2）
- 一般告示牌一行的上限是 89 像素：「STARLUX AIRLINES」90 放不下、「STARLUX AlRLINES」89 放得下；「プレミアムエコノミー」89.25 放不下（作者確認過，所以把「ー」省掉），「プレミアムエコノミ」78.75 放得下
- 吊牌：存檔裡的吊牌放得下「手荷物お預け」（71.25），比 Java 版吊牌的上限 60 還寬，看起來基岩版的吊牌沒有比較窄。保守起見，吊牌每行不超過 71
- 排版時一般告示牌每行不超過 86，留 3 像素的餘裕；價格符號打成全形「￥」也不超過 89
- 同樣的字數，漢字多的那一行比較容易超過，例如「鉄観音ミルクティー」只有 9 個字，就已經 92 像素
- 2026-11-10 的第一版是用存檔推算的，漢字的寬度估得太窄，有 5 行其實會換行；這一版改用字型圖量，已經改掉

### 字體

作者 2026-11-10 定的規則。一行全是半形英數字和符號，遊戲會用原版的像素字體；同一行只要混了日文、中文、「¥」（作者親眼看到 ¥ 也會換）或全形符號，整行就換成另一種字體。

- **同一個地方的告示牌（同一間店的菜單、同一個公告欄、同一組指標），英文要不要單獨一行要統一**
- 建議固定讓英文單獨一行，價格放在日文那一行或自己一行。這樣英文永遠是像素字體，價格永遠是另一種，即使字體不同也整齊
- 不要一下子英文自己一行、一下子英文後面接「¥850」：同一張菜單會有的英文是像素字、有的不是
- 全形的「～」「・」「／」「＋」「＆」放在英文行裡也會換字體，英文行裡要用半形的「~」「/」「+」「&」

### 排法

- 一般告示牌放 2 個品項：日文品名一行，英文加價格一行。日文品名短的時候，改成日文加價格一行、英文一行（第一版的排法，會讓英文的字體不一致；以後照上面的[字體](#字體)規則，英文單獨一行）
- 吊牌放 1 個品項：日文、英文、價格各一行
- 名字太長的拆兩行：タピオカ鉄観音ミルクティー、鉄観音ミルクティー、黒糖琥珀タピオカラテ、ゆし豆腐そば和價格
- 日文縮短的：ポーたま的「島豆腐の厚揚げ油みそ」寫成「島豆腐の厚揚げ」；沖縄そば省略「（三枚肉）」；功夫麺省略「（小碗）」（只有這個份量）
- 英文放不下時省略，日文和價格優先：GEORGE 的兩種牛排（只寫重量）和肉大盛、Larna taco 的大盛和套餐、瑠璃的套餐和麺大盛、春水堂的兩種珍珠飲料和鉄観音ミルクティー、ポーたま的各個口味
- 英文縮短的：コーヒーフラッペ只寫「Frappe」、抹茶フラッペ只寫「Matcha」、ゆし豆腐そば只寫「Yushi-Tofu」、てびちそば只寫「Tebichi」
- 遊戲裡不好打的字母換掉：Frappé 寫成「Frappe」
- 先用現有的空白告示牌；不夠的標「新增」，由作者自己放。Claude 的建議：跟同一家現有的告示牌排在一起，用同一種木頭。表裡的「（空）」是空白的一行
- 現有空白告示牌的排列方向沒有對照，同一家店的告示牌要怎麼排，照作者看的方向調整
