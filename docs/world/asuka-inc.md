## 定位（已定）

- 本國唯一的本土財團，業務包山包海，確實很有錢（作者 2026-11-09，見[商業](commerce.md#商業版圖)）

### 合理性

- 一個私人財團同時有地產、航空、飯店、重工，有現成的先例：香港的太古集團（Swire）是英國洋行出身，旗下有太古地產、國泰航空（香港事實上的載旗航空）、Swire Hotels，以及修飛機的港機工程
- 三星集團旗下有三星電子、三星重工（造船）、做建設的三星物產、新羅飯店，主題樂園愛寶樂園也是它的；新世界百貨原本也屬於三星，1990 年代才分出去
- 小國由一個財團佔很大比重：三星集團的出口約佔韓國的兩成；Nokia 全盛時期約佔芬蘭 GDP 的 4%
- 子公司都是全資：Asuka Inc. 是不上市的私人公司，集團裡的公司也都不上市；三星、太古旗下則有很多上市公司，這點不同

## 待決定事項

- [ ] **航空是不是 Asuka Air**，Claude 的提案：是。Asuka Air 現在的設定是國家載旗航空，股權沒有寫；由私人財團持有的載旗航空有先例，大韓航空屬於韓進集團，國泰航空屬於太古集團。[交通](transport.md#地勤與票務)裡 IS 自己的地勤公司、跑小島航線的子公司，也就都在航空這一家底下
- [ ] **Minecraft Studio 歸哪一家**，Claude 的提案：旅遊。先例是三星的愛寶樂園
- [ ] **控股公司是不是 Asuka Inc. 本身**，Claude 的提案：是，Asuka Inc. 就是集團的母公司，自己不做生意，只持有各子公司、決定集團的方向，在總部大樓辦公
- [ ] **子公司的名字**，Claude 的提案：一律叫「Asuka ○○」，例如 Asuka Properties、Asuka Heavy Industries、Asuka Electronics；日文用不用漢字「飛鳥」（飛鳥重工、飛鳥電子），作者決定。電信和百貨是一般人天天看到的品牌，名字另外取，像 SK 集團的電信叫 SK Telecom、從三星分出去的百貨叫新世界
- [ ] **重工做什麼**，Claude 的提案：主力是茉波城市的造船廠，也就是日本海軍船塢改成的民間造船廠（見[地理](geography.md#中北部茉波城市)），先例是三星重工、三菱重工的造船；另外可以做鐵道車輛和發電設備
- [ ] **科技電子做什麼**，Claude 的提案：茉波城市北部的晶圓廠由它和外國的晶圓代工廠合資，先例是新加坡的 SSMC（台積電與 NXP 合資），見[世界觀總覽](overview.md#產業)；另外做電子零件和軟體
- [ ] **電信的市占**，Claude 的提案：約 35%，Spoton 約 45%，第三家約 20%；家用光纖照規定向 Spoton 批發線路，見[電信](telecom.md#業務)
- [ ] **百貨開在哪裡**，Claude 的提案：旗艦店在 CBD 或舊市區，茉波城市一家
