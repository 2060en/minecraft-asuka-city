# 地理與主要設施

> 根據舊版的規劃鳥瞰圖與作者說明整理。

---

## 列島概要

- 以沖繩本島為參考的列島，四周是海
- 遊戲中範圍約 8000 × 8000 格；設定上相當於沖繩本島的規模（長約 100 公里），見[比例尺與尺寸規範](../scale.md)
- 由主島、南方離島與數個小島組成

---

## 主島

### 西南部：Asuka City（飛鳥市）

首都，也是全國最大的都市。

| 區域 | 內容 | 參考 |
| --- | --- | --- |
| 市中心 | CBD、Asuka Inc. 總部 | 東京、大阪的 CBD |
| 舊市區 | 靠近港口，有許多明治時期的巴洛克建築、舊帝國大學 | 京都、東京、台北明治大正時期的建築與用途 |
| 舊車站 | 歷史建築 | 第二代台北車站 |
| 皇居離宮 | 規模不大的離宮與庭園 | 京都御苑的氛圍 |
| 港口區 | 大型港口、貨櫃港（Cargo Port） | 橫濱 |
| 南部濱海 | 濱海區域 | 鎌倉 |
| 其他 | 大學、OUTLET、Minecraft Studio | — |

交通設施：

- 地鐵：市區內有多條路線
- 機場：緊鄰都市東側，只有一條跑道（遊戲中約 1000 格，設定上 3000 公尺）。原本規劃的斜向跑道已取消

### Minecraft Studio

Minecraft 主題樂園，把 Minecraft 的元素融入遊樂園。

- 林地府邸：其中一個遊樂區
- 跑跑卡丁車區：以沙漠旋轉工地為造型的賽車遊樂設施

### 中北部：第二大都市

| 區域 | 內容 | 參考 |
| --- | --- | --- |
| 港口 | 深入內陸的海灣港口 | 基隆、長崎、神戶 |
| 空軍基地 | 有跑道的軍用機場（舊規劃圖上標為航空自衛隊） | — |
| 其他 | 工業區、漁港 | — |

### 中部：西北突出的圓形半島

遊戲中建築還沒蓋到，但設定上是既有地區，不是新市區。

### 北部

| 區域 | 參考 |
| --- | --- |
| 平原 | 北海道的平原（旭川） |
| 濱海 | 台北北海岸 |
| 最北的海岸 | 稚內、根室 |
| 山地 | 台灣中央山脈，但會下雪 |
| 山間盆地 | 富良野、策馬特（Zermatt）、紐西蘭 |

設施：

- 核電廠
- 大學（北端）

## 南方離島

完全參考石垣島、宮古島。

- 只有一個小鎮
- 港口、海生館
- 最南端：小機場，參考下地島機場

---

## 交通

- **縱貫鐵路**：從西南部的港口出發，經過 Asuka City，沿東南海岸一路到北端
- **公路**：連接各地區
- **地鐵**：Asuka City 市區內的多條路線
- **機場**：Asuka City 機場、第二大都市的空軍基地、南方離島的小機場
- **黑潮特快**（構想）：海底鐵路隧道，從那霸經過本國開往九州，見[世界觀總覽](overview.md#黑潮特快)
