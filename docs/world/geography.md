> 根據舊版的規劃鳥瞰圖與作者說明整理。

## 列島概要

- 以沖繩本島為參考的列島，四周是海
- 位置：奄美大島西北方，取代現實中寶島、小寶島（吐噶喇列島）的位置
- 遊戲中範圍約 8000 × 8000 格；設定上相當於沖繩本島的規模（長約 100 公里），見[比例尺與尺寸規範](../scale.md)
- 由主島、南方離島與數個小島組成
- 主島西北方的大島：目前沒有任何設定，先忽略，當作未開發的蠻荒之地

## 主島

### 西南部：Asuka City（飛鳥市）

首都，也是全國最大的都市，人口約 90 萬，高度集中。都市風貌以日式城市為主。

| 區域 | 內容 | 參考 |
| --- | --- | --- |
| 市中心 | CBD、Asuka Inc. 總部、主權基金總部 | 東京、大阪的 CBD |
| 舊市區 | 靠近港口，有許多明治時期的巴洛克建築、舊帝國大學、舊英國領事館 | 京都、東京、台北明治大正時期的建築與用途 |
| 舊車站 | 歷史建築 | 第二代台北車站 |
| 總督府 | 正對車站、白宮樣式的建築，靠近港口；日本時代的總督府，現為行政中心 | 台灣總統府、新加坡 Istana |
| 内閣府 | 總督府後方的政府大樓，和總督府組成一個園區 | 日本首相官邸（新舊官邸同在一區） |
| 皇居離宮 | 規模不大的離宮與庭園，現為國賓館兼中立會談的場地 | 京都御苑的氛圍、京都迎賓館 |
| 外交區 | 皇居離宮周邊的五座使館園區，合計約 200 × 200 格 | 東京港區、柏林的使館區 |
| 港口區 | 大型港口、貨櫃港（Cargo Port） | 橫濱 |
| 南部濱海 | 濱海區域 | 鎌倉 |
| 其他 | 大學、OUTLET、Minecraft Studio | — |

交通設施：

- 地鐵：市區內有多條路線
- 機場：緊鄰都市東側，只有一條跑道（遊戲中約 1000 格，設定上 3000 公尺）。原本規劃的斜向跑道已取消

### Minecraft Studio

Minecraft 主題樂園，把 Minecraft 的元素融入遊樂園。

- 林地府邸：其中一個遊樂區
- 跑跑卡丁車區：以沙漠旋轉工地為造型的賽車遊樂設施

### 中北部：第二大都市

人口約 55 萬，名稱待決定。氛圍像基隆、神戶、門司港。市區環繞港灣一圈，西半部就在「西北突出的圓形半島」上。腹地不大，港灣之外都是山地丘陵，是起伏很大的山城（像基隆、長崎）。

#### 歷史

| 時期 | 事件 | 先例 |
| --- | --- | --- |
| 明治時期 | 天然深灣成為全國的主要港口，靠出口北部山地的礦產而繁榮 | 基隆之於九份、金瓜石；小樽之於北海道的煤礦 |
| 日本統治時期 | 日本海軍的要港，城市北部設有海軍航空隊機場 | 佐世保、吳、橫須賀，都是深灣山城 |
| 獨立後 | 海軍船塢改為民間造船廠 | 新加坡三巴旺造船廠，由英國海軍基地改建 |
| 1960～70 年代 | 貨櫃化需要大片平地，山城的海灣無法擴張，新的貨櫃港改建在 Asuka City，港口地位跟著轉移 | 基隆被台北港、高雄港取代 |

#### 現在的產業

| 產業 | 先例 |
| --- | --- |
| 造船與修船 | 新加坡三巴旺造船廠、長崎 |
| 渡輪港（開往大阪、橫濱的過夜渡輪）、港口懷舊觀光 | 新門司、神戶的長途渡輪碼頭；門司港懷舊區 |
| 漁港與水產加工 | 基隆 |
| Asuka City 的通勤城 | 基隆之於台北 |
| 自衛隊港口 | 海軍要港時代留下的區域 |
| 半導體（晶圓廠） | 中部科學園區台中園區緊鄰清泉崗機場 |

人口比長崎（約 40 萬）、基隆（約 36 萬）都多。腹地小的山城要撐住這個人口，通勤城的角色很重要；建造上需要大量依山而建的住宅，可以搭配斜坡電梯或纜車（像長崎）。

#### 設施

| 區域 | 內容 | 參考 |
| --- | --- | --- |
| 港口 | 深入內陸的海灣港口、渡輪碼頭、造船廠 | 基隆、長崎、神戶、門司港 |
| 空軍基地 | 位於城市北部，日本海軍航空隊機場的舊址，目前只有預定地；跑道約 500～600 格 | — |
| 晶圓廠 | 城市北部、空軍基地旁的平地，一座中小型晶圓廠 | 新加坡的 SSMC、聯電；中科台中園區 |
| 其他 | 工業區、漁港 | — |

### 中部：西北突出的圓形半島

第二大都市的西半部。市區環繞港灣一圈，有一部分就在這個半島上；規劃圖上半島的西岸是工業區。遊戲中建築還沒蓋到，但設定上是既有地區，不是新市區。

### 北部

| 區域 | 參考 |
| --- | --- |
| 平原 | 北海道的平原（旭川），只參考景觀，平地不會經常下雪 |
| 濱海 | 台北北海岸 |
| 最北的海岸 | 稚內、根室 |
| 山地 | 台灣中央山脈，但會下雪（雪國） |
| 山間盆地 | 富良野、策馬特（Zermatt）、紐西蘭（雪國） |

設施：

- 核電廠
- 大學（北端）
- 舊礦山小鎮：位於北部山地的南側，明治時期的礦山，礦產從第二大都市的港口出口；礦場關閉後成為觀光地（像九份、金瓜石）。礦種待決定
- 牧場：北部山地南側的西北海岸一帶
- 富良野（山間盆地）：縱貫鐵路的終點
