# 命名

記錄國名、地名的命名原則、討論流程、黑名單與地名表。

> 「待決定」的項目還在考慮中，Claude 的提案整理在最後的[待決定事項](#待決定事項)。

---

## 命名原則（已定）

每個名字都要滿足兩個條件：

1. **對作者有現實意義**：這是重點。通常取自作者喜歡的人事物，例如 Asuka 取自齋藤飛鳥
2. **符合設定**：在世界觀裡有說得通的由來

兩者分開處理：先依現實意義決定名字，再依下方的地名分層替它編一個設定上的由來。

名字的漢字一律用日文漢字（日本現行的字體），例如寿豊、与那国，不用壽豐、與那國。作者的輸入法打出來是繁體，記錄時要轉換；文件的敘述仍用繁體中文。

國名尤其一定要對作者有意義。

## 討論流程（已定）

1. Claude 提出可以從作者生活的哪些方面發想
2. 作者分享那個方面的喜好
3. Claude 根據喜好提出候選名，附上設定上的由來
4. 作者回饋，反覆討論到定案

### 作者提出的取名方法

1. 找一個作者喜歡的人事物
2. 取它的英文或其他語言的名字，直接用日文的發音唸出來
3. 每個音配上漢字（當て字，像明治時期把 America 寫成亜米利加）

例子：紐西蘭的 Tekapo → てかぽ → 手賀保、照香歩。

毛利語的音節結構和日文很像（每個音都以母音結尾，母音也是 a、i、u、e、o），很適合這個方法，轉出來的名字也像「島民語言的地名套上漢字」。

國名也可以考慮「〇〇州」的形式。

## 地名分層（暫定）

地名跟著歷史一層一層疊上去：明治開發像北海道，外地統治像日治台灣，英國託管像香港，獨立後像馬來西亞。

| 時期 | 命名方式 | 現實先例 | 主要出現在 |
| --- | --- | --- | --- |
| 明治以前 | 島民的語言：北部阿依努語系、中部類似毛利語的南島語、南部琉球語 | 北海道的愛奴語地名（札幌、ニセコ） | 鄉間、山、河、海岬 |
| 日本外地時期 | 原地名套上讀音相近的漢字，或日本人另外取名 | 打狗→高雄、札幌 | 舊市區、明治時期開發的城鎮 |
| 英國託管 | 舊地名改用羅馬拼音，新設施取英文名 | 香港的 Victoria Harbour、Queen's Road | 港灣、幹道、託管時期的新區、山地度假地 |
| 獨立後 | 大致沿用，部分英文名改成日文名；新東西以日文命名，常附英文 | 馬來西亞：Jesselton 改名 Kota Kinabalu，Cameron Highlands 沿用 | 新市鎮、地鐵站、機場 |

英國託管時期的羅馬拼音不一定照標準拼法，就像香港地名的拼法。

島民的設定見[世界觀總覽](overview.md#民族)。

## 國名（已定）

| 項目 | 名稱 |
| --- | --- |
| 正式國名 | 津蘭賀千良（ツランガチラ） |
| 國際英文名 | Tu Rangatira |
| 常用簡稱 | 津蘭（ツラン） |
| 一個字的簡稱 | 津（例如日津関係） |
| 更常用的別稱 | 茉波 |

- 原文都是毛利語，也就是中部島民的語言：Tū Rangatira 是「像酋長一樣站立」，Māhaki 是「謙遜、溫和、寬容」
- 漢字照作者的方法用當て字：津（つ）蘭（らん）賀（が）千（ち）良（ら）；茉（ま）波（は）城（き）
- ツランガチラ是漢字的讀音。現代的片假名轉寫是トゥランガティラ，ツランガチラ比較有明治時期的味道，像 Tahiti 寫成タヒチ
- 不加「共和國」這類表示政體的字

### 整體意義：禮儀之邦

正式國名 Tu Rangatira 是「像酋長一樣站立」，別稱 Mahaki 是「謙遜、溫和、寬容」。兩個名字合起來，是一個抬頭挺胸、又謙遜有禮的國家：不卑不亢，也就是禮儀之邦。這也符合本國的角色：靠策略而不是武力生存，替各方居中、招待外賓、舉行中立會談。

### 別稱的由來

| 時期 | 名稱 |
| --- | --- |
| 日本、英國統治時期 | 茉波城（Mahaki） |
| 1960 年代獨立時 | 改名為津蘭賀千良（Tu Rangatira），從「謙遜」改為「像酋長一樣站立」，象徵這個國家站了起來 |
| 現在 | 民間仍習慣叫舊名的簡稱「茉波」，像緬甸與 Burma、斯里蘭卡與 Ceylon |

### 茉波一系列的名字

| 名稱 | 對象 |
| --- | --- |
| 茉波 | 本國的別稱 |
| 茉波城 | 範圍比較大的地名（確切範圍待確認），也是日本、英國統治時期的領地名稱 |
| 本島、茉波本島、茉波島 | 主島 |
| 茉波城市（Mahaki City） | 第二大都市。一定要加「市」，因為茉波城是範圍比較大的地名 |

第二大都市是這一系列名字的源頭。明治到日本統治時期，全國的主要港口就在這裡，外國人最早認識的是這個港口，整個殖民地因此被叫成茉波城，像香港原本只是港邊一個村子的名字。國名來自首都以外的城市也有先例：摩洛哥（Morocco）的國名來自舊都馬拉喀什（Marrakesh），不是現在的首都拉巴特。

## 待決定事項

- [ ] **茉波城的確切範圍**，Claude 的提議：茉波城是整個群島的地理名稱，也是殖民時期的領地名稱；三層的關係像沖縄（縣、群島）、沖縄本島、沖縄市
- [ ] **別稱「茉波」的讀音與英文**：照之前「沫波」的例子讀まは；英文是否沿用殖民時期的 Mahaki，待確認
- [ ] **照作者的方法，從紐西蘭的地名轉出來的地名**，Claude 的提案：

  | 地名 | 原名 | 用在 | 理由 |
  | --- | --- | --- | --- |
  | 照香歩（てかぽ） | Tekapo | 北部的山間盆地（縱貫鐵路的終點，目前暫稱富良野） | Tekapo 就在紐西蘭的 Mackenzie 盆地，而紐西蘭本來就是本國山間盆地的參考地 |
  | 海光浦（かいこうら） | Kaikōura | 靠海的小鎮 | 讀音完全吻合，字面是「海光之浦」；Kaikōura 以賞鯨聞名 |
  | 青良木（あおらき） | Aoraki | 北部山地的最高峰 | Aoraki 是紐西蘭的最高峰（Mount Cook） |
- [ ] **渡瀬用在哪裡**，Claude 的提案：本島北岸面向七島灘的海角或港口。渡也有渡船的意思，適合渡輪碼頭所在的地方。架空世界裡，從北邊海上通過的生物分界線就以這裡命名，叫渡瀬線
- [ ] **大田**，Claude 的提案：取自安俞真的出生地大田（대전，Daejeon）。用在 Asuka City 機場一帶的地名，像東京的羽田機場就在大田區
- [ ] **瑠璃（Ruri）**：作者決定保留，用在哪裡還沒想好。Claude 原本提議當國名：
  - 現實意義：取自大島璃音的「璃」
  - 設定上的由來：本國位在黑潮流出吐噶喇海峽的位置，四周是黑潮深藍色的海，因此稱為瑠璃
  - 瑠璃源自梵語，經佛教傳入東亞，是七寶之一，不專屬中日韓台任何一方（像新加坡的國名也源自梵語）；本國又剛好取代現實中「寶島」的位置
  - 群島稱瑠璃諸島，主島照奄美大島的模式稱「瑠璃大島」，藏著「大島璃」
  - 缺點：瑠璃在日本也是常見的女性名字；中文的「琉璃」多指有色玻璃
- [ ] **大島**：作者決定保留，用在哪裡還沒想好。Claude 原本提議當主島的島名：取自大島璃音。群島中最大的島稱大島是日本常見的命名方式（奄美大島、伊豆大島），需要區別時前面加國名或群島名。主島西北方另有一座大島，目前沒有設定
- [ ] **名井的細節**：Claude 的提案：
  - 用作島上小鎮的名字；之後也可以考慮當正式島名（一島一鎮，像与那国島和与那国町）
